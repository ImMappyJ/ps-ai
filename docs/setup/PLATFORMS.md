<h1 align="center">选择生图平台</h1>
<p align="center"><strong>简体中文</strong> · <a href="PLATFORMS.en.md">English</a> · <a href="../../README.md">返回首页</a></p>

当前开发分支可以在面板中选择 ComfyUI、Nano Banana、GPT Image 和 BaiLian。已发布的 **v0.4.0 不包含平台切换或光影重塑**。请先按 [源码构建](../../README.md#从源码构建) 加载开发版；本页说明当前代码，平台实际效果和新控件的 Photoshop 验收尚未完成。

## 选择哪条路径

| 面板选项 | 推理位置 | 需要准备 | 本机连接 |
| --- | --- | --- | --- |
| ComfyUI | 自己的 ComfyUI | 兼容后端、节点和模型 | 默认 `http://localhost:8188`，地址和端口可改 |
| Nano Banana | Google Gemini API | 对应项目的 API Key、模型权限 | `http://127.0.0.1:8192`，自动管理 |
| GPT Image | OpenAI Images API | 对应项目的 API Key、模型权限 | `http://127.0.0.1:8193`，自动管理 |
| BaiLian | 阿里云百炼 API | 中国内地端点的 API Key、模型权限 | `http://127.0.0.1:8191`，自动管理 |

ComfyUI 直接连接现有服务，不启动平台中转。三个平台使用独立任务目录和独立 Key。平台模式不需要本地推理模型，但本机需要 **Node.js 24+**。网页订阅不等于 API 权限。

## 在面板中配置平台

1. Windows 安装 Node.js 24 或更新版本。在终端运行 `node --version` 确认，再重新启动 Photoshop，让它读取更新后的 PATH。
2. 展开“模型与连接”，在“后端类型”选择平台。平台地址自动填写并锁定，不能填成第三方 API 的 URL。
3. 在 **API Key** 框输入对应平台的 Key，点“保存 Key”。首次启动会弹出 Photoshop 的外部程序授权，请确认启动的是 PS-AI 本地服务。拒绝后可重新连接。
4. 点“扫描模型”，选择账号可访问的模型。“保存配置”保存模型选择；点“连接”检查本机服务和配置。连接和扫描不会生成图片，也不验证平台账户权限。
5. 选择任务模式，输入提示词，再点“生成候选”。生成时才上传图像和提示词。先用一张候选检查效果。

输入框保存后会清空，以“Key 已保存（加密）”表示状态。Key 使用 Photoshop 的 UXP secureStorage 按插件加密保存，连接时只传给带令牌认证的本机服务；服务仅在内存中使用它。JSON 导出、任务历史和阶段日志不包含 Key。CCX 与 Portable 的数据独立；卸载、清理插件数据或账户凭据损坏后，可能需要重新输入。

更换平台后，原来的模型选择会保留。切回 ComfyUI 会恢复之前的地址、模型映射和位深。生成期间配置控件锁定。存在未完成任务时，先按原 ID 恢复；同一服务实例不允许更换或清空该平台 Key，重启后也应使用原任务所属账户。

## 模式和参数限制

| 功能 | ComfyUI | Nano Banana | GPT Image | BaiLian |
| --- | --- | --- | --- | --- |
| 文字生图、局部编辑、服装、参考、场景、光影重塑 | 支持对应工作流 | 已实现编辑接口 | 已实现编辑接口 | 已实现编辑接口 |
| 透明特效／氛围素材 | 支持，需检查底色与杂边 | 禁用 | 已实现，需检查 alpha | 仅 Qwen 2.1 模型开放 |
| 设置步数 | 可以 | 平台控制 | 平台控制 | 平台控制 |
| 设置种子 | 可以 | 禁用 | 禁用 | 可以 |
| 输出位深 | 8 位／可选 SDR16 | 8 位 | 8 位 | 8 位 |
| 进度／取消 | 真实阶段和采样步数，按任务取消 | 阶段／停止后续候选 | 阶段／停止后续候选 | 阶段／停止后续候选 |

“已实现”说明请求路径存在，不代表效果已经验收。模型能力清单决定可用操作、种子范围、输入数量、像素和长宽比。禁用的素材模式不能生成；超出尺寸等限制时会在上传前拒绝。不同平台的模型清单与几何处理见 [百炼](../providers/BAILIAN.md)、[Gemini](../providers/GEMINI.md)、[OpenAI](../providers/OPENAI.md)。

## 停止、恢复和排错

- “停止后续候选”保留当前平台请求继续执行，不能保证中断或停止计费。用“恢复任务”查询原 ID，不要反复创建。
- 切到 ComfyUI 不会关闭已经运行的中转服务。“停止本地服务”会停止三个平台的本机监听并等待当前工作收尾；再次连接平台时启动。关闭 Photoshop 不会自动结束独立 Node 进程。
- 没有启动：检查 Node 版本、Photoshop 启动授权、端口 **8191–8193** 是否被占用。CCX 和 Portable 只启用其中一种；两份插件同时使用自动中转会发生端口冲突。
- 提示缺 Key：在当前平台重新保存。401／403 要检查账号、模型权限和地域；429 检查额度与频率。
- 提示 PNG／颜色不符：保留原始输出，不放宽解码。未标记 sRGB 的输出默认拒绝；确认色彩解释后，可用下方的手动服务配置明确的 `PSAI_*_ASSUME_SRGB` 策略。
- 服务异常退出：任务仍在插件数据目录的 `relay/<平台>/`。确认锁文件记录的 PID 已退出后，才移除遗留 `gateway.lock`。备份时保留整个目录，不能只拷贝 JSON；不要把私人图片、提示词或目录上传到 Issue。

## 手动服务与其他系统

自动启动器目前只适用于 Windows，Node 运行时不随插件分发。需要其他系统、自选端口、百炼其他地域／业务空间或显式色彩策略时，按各平台指南手动启动服务，在面板选择“手动适配服务（进阶）”，填写本机地址。手动服务从环境变量读取 Key，不使用面板的保存 Key 按钮。它与自动中转的数据目录相互独立。

自动服务的本机令牌只用于当前电脑上的插件连接，不是公网账户系统。不要映射端口或将服务开放到公网。
