# 光影重塑工作台

中文 | [English](RELIGHT.en.md)

本指南描述开发版的结构化布光链路。现有发布包不包含此升级。原图、布光示意和 AI 结果是三个不同对象；本地示意不是最终生成结果，也不是物理精确渲染。使用步骤见[用户指南](../usage/USER_GUIDE.md#relight)，供应商协议见[后端合同](BACKEND.md)。

## 现状与能力

| 项目 | 范围 |
| --- | --- |
| 宿主 | Photoshop 27+，UXP manifest v5、API v2；TypeScript/esbuild，沿用DOM与Spectrum控件 |
| 原图 | 指定文档的可见合成图，选区外可包含上下文；不是只读活动图层，也没有新增自动分割 |
| 范围 | 提交时固定的灰度选区 `M*(1-P)`，保护区和文档坐标不由模型决定 |
| 布光控制 | 点光、聚光、平行光和全局环境光；通过语义文本表达，不是供应商的逐灯控制API |
| 原生窗口 | PS27实测大尺寸UXP dialog、PNG dataURL、绝对定位DOM标记和pointer capture拖动可用 |
| 原生操作限制 | 打开的dialog内调用既有图层回写会失败；必须关窗后短暂捕获/回写，再恢复工作台 |
| 模型 | 复用ComfyUI Qwen2.1、Bailian、Gemini、OpenAI Images；不增加服务、深度/法线/分割模型 |
| 输出 | 完整结果作为NORMAL新图层与可编辑蒙版；实验补偿应用受独立验证门控 |

初始容器探针使用一次性128×96合成文档。对话框内应用实际返回“建立命令不可用”，闭窗后使用既有adapter写入成功；原图身份往返49152个RGBA通道最大差0，原有文档ID和历史未变。这验证容器与短回写方案，后续工作台、性能和生成链路分别验证。

最终源码在PS27原生脚本中通过点光、聚光目标与平行光方向的实际拖动、连续手势及撤销/重做。窗口1040×740调整为1160×820后，适应比例重新计算且场景指纹不变；画外灯可找回。可拖标记使用稳定DOM节点和pointer capture。静止窗口的图片加载/resize循环已修复；关闭后事件、预览缓存和图片引用释放。源码脚本不是安装后的插件面板验收。

API依据：[Adobe UXP modal dialogs](https://developer.adobe.com/uxp/guides/how-to/add-modal-dialogs/)、[executeAsModal](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/executeasmodal)、[Imaging API](https://developer.adobe.com/photoshop/uxp/2022/ps_reference/media/imaging/)。dialog会阻止宿主交互；生成时可关闭编辑窗口，稍后重开恢复配置。

## 场景与坐标

唯一结构化状态为版本1的 `RelightScene`，参数版本为1。来源绑定包含文档、来源图层ID、会话、历史、像素摘要、快照标识、原生尺寸、处理范围、ICC/模式/位深与蒙版引用。来源图层ID用于描述可见合成的来源，不改变实际捕获方式。图像和二进制蒙版不嵌入场景JSON，密钥不进入场景或任务历史。

每个光源有稳定ID、名称、角色、类型、启用状态、位置锁定及适用参数。最多8个光源是界面限制，不是模型精度承诺。主光/补光/轮廓光/自定义是角色，与点光/聚光/平行光类型分开。关闭灯会改变请求；隐藏标记只改变显示。

处理区域左上角为原点，x向右、y向下。x/y及聚光目标按区域宽高归一化，允许 `[-1,2]` 的画外位置。文档点为 `(bounds.left+x*width, bounds.top+y*height)`；模型坐标再映射到其内容矩形，填充属于画布变换；视口坐标还包含适应比例、缩放和平移。屏幕像素不直接传给模型，调整窗口或显示缩放不改场景。

| 参数 | 数值约定 |
| --- | --- |
| 光强 | 相对强度0–4，不是流明/照度/曝光值 |
| 相对Z | -1–1，只表达前后意图，没有恢复三维场景 |
| 范围 | 处理区域短边的0.05–3倍，仅点光/聚光生效 |
| 柔和度 | 0–1 |
| 聚光角 | 5–160度，配合目标点 |
| 平行光 | 方向-180–180度，仰角-90–90度；位置不解释为距离衰减 |
| 色温 | 2000–12000K；与自定义 `#RRGGBB` 互斥 |

全局参数包含环境光、保留原光并补光/尽量重塑、阴影强弱/柔和度、内容保持要求和用户补充。序列化值必须通过版本、类型、有限数、范围、ID唯一性和数量校验。

## 预览和请求

CPU预览只在缩略sRGB8副本上计算光照影响场，使用真实灰度编辑范围，保持Alpha。图标、名称、方向和控制手柄由DOM单独显示。它不推断遮挡、投射阴影、材质高光或物理反射；只有点击生成才发起请求。

每次来源快照只准备一次最大边480的小图与按可见Alpha贡献重采样的蒙版；透明可编辑像素不能给受保护的可见内容带来编辑覆盖率。拖动复用缓存，取消过时计算，编码PNG前再次检查任务是否仍有效。PS27核心性能探针使用4096×3072 sRGB8与八盏混合光源：来源捕获6606ms，缓存准备11ms；12次热运行的渲染／PNG编码／图片加载算术中位数为52.5／43／11ms，总计中位107.5ms、nearest-rank p95为118ms。首次总计152ms。这是一次核心函数基线，不是最终拖动FPS或所有机器的性能保证。

工作台另以4096×3072来源、八盏灯、480×360缓存测量10次真实DOM参数提交到新图片load事件：111–124ms，中位116.5ms，p95按nearest-rank取124ms。2.513秒静止采样期间，窗口/dialog resize与图片load计数均无增长。这是一次宿主预览更新延迟测量，不是实际绘制帧率，也不构成长时间稳定性保证。

编译器输出稳定语义文本，先用“左上暖色主光”等自然方位、颜色、强弱描述，再保留适用数值，包含所有启用光源及全局意图。禁用灯不进入请求。编辑器实现说明和精度声明留在UI与元数据中。补充描述的明显冲突会提示；这不是完整的自然语言冲突检测。结构化状态独立保存，不能从最终提示词反向猜测灯参数。

| 后端 | 实际条件输入与几何 |
| --- | --- |
| ComfyUI | 干净source第一、可选灰度guide随后、reference最后；Qwen2.1图、保存节点8 |
| Bailian | 按source/guide/reference角色绑定，严格结果尺寸；支持能力声明内的种子 |
| Gemini | source/guide居中填入1024方形，输出反裁剪；无可配置种子，guide是视觉参考 |
| OpenAI | source/reference是images，guide转单独native mask；source/mask同变换并反裁剪；无可配置种子 |

灯坐标描述相对于未填充的源内容。不会向平台协议添加虚构的灯光、深度或法线字段。干净原图始终是主要内容依据，本地示意不替代原图。八灯精度、文字/Logo、身份与纹理保持都需检查。

任务另存提交场景、场景指纹、实际供应商/模型、净化后的能力快照、模型输入尺寸、颜色信息和结果标识。只有供应商支持时才记录真实种子；协议的占位0不代表支持种子。场景在提交时冻结，之后编辑会使旧结果出现过期提示；取消或过时请求不应成为新的成功结果，原UUID仍用于恢复。

## 完整结果与颜色

完整结果表示本次处理区域的完整重布光内容。图层使用NORMAL和可编辑蒙版，保留原始像素，支持不透明度调整和单步撤销。同次捕获重复应用只替换插件自己的候选层。来源文档关闭、历史/ICC/会话改变时拒绝回填，结果仍可导出。

原生16位来源保留为独立缓存，模型使用单独的sRGB8输入；平台输出为sRGB8，ComfyUI可选PNG16 SDR保存。它们不是HDR或原生16位模型生成。Imaging API按目标文档转换结果，未知ICC或不支持的文档模式继续明确拒绝。

半透明来源复用既有安全clipping策略，避免同一Alpha在源层与结果层重复叠加。多层来源无法验证安全底层时，应在副本合并可见层后重新读取，或导出后手工合成；不能绕过检查。

PS27的512×512 sRGB16一次性文档保留了非257倍数的原生通道值。使用此前保存的真实Qwen8位结果，通过实际工作台与adapter连续应用两次，第二次替换候选且图层总数不增；逐次撤销分别恢复第一候选与原图。原始图层、候选恢复及原图恢复各比较1,048,576个native16 RGBA值，最大差均为0。该测试使用受控host回调与已有结果文件，不是重新推理或完整面板存储/网络端到端验收，也不代表模型颜色往返无损。

## 实验补偿

基线限定为同尺寸、同位深、全不透明且明确约定的编码sRGB数值。不是线性光空间，也不是任意ICC可转换的普通照片。源 `B` 与结果 `R` 归一化到0–1，逐RGB通道计算：

- `R<B`：`D=R/B, L=0`。
- `R>B`：`D=1, L=(R-B)/(1-B)`。
- 相等：`D=1, L=0`。
- 暗后亮重构：`C=1-(1-B*D)*(1-L)`。

黑白边界按分支避免除零。量化后的D/L需重新合成，报告RGB最大绝对差、平均绝对差和RMSE，单位同时注明码值与归一化值。透明、ICC未知、不同位深或未验证混合条件拒绝补偿；完整结果保留。

PS27独立合成探针在NORMAL隔离组内放固定底图，依次为暗部Multiply和亮部Screen，100%不透明、无蒙版；补偿图按相同文档编码数值直接写入，不随意ICC转换。sRGB8和AdobeRGB8测试最大差0；16位最大差2/65535、平均约0.284码值。Display P3因本机未安装该配置跳过。此数值测试不是AdobeRGB补偿产品支持声明，也不验证真实内容质量。

**补偿应用仍未开放。** 数学重构或原生合成通过，不能证明这些层只含光照；模型对五官、Logo和纹理的修改也会进入补偿。真实图片视觉质量、蒙版/Alpha及混合设置的完整验收未完成时，不创建补偿层、不与完整结果叠加。

## 验证范围

自动测试与模拟面板测试验证状态、坐标、编译和失败路径；原生探针验证特定PS27 API组合。本机ComfyUI/Qwen2.1以512×512、固定种子23491和25步完成编译器对照：初版纯数值表达失效，自然方位与色词优先后，合成球体左右暖光与冷光可辨。公开NASA/scikit-image照片的实际输出保留人物姿态和服装／背景大轮廓，冷暖可辨；徽章小字和微观纹理未认定保真，未因此开放补偿。

完整源码面板的原生网络联调在PSJS首次GET时被权限拒绝，0上传、0推理提交；原文档未变。Adobe将[脚本Network能力标为不支持](https://developer.adobe.com/photoshop/uxp/2022/scripting/how-it-works/)，应在已安装的UXP插件中验收网络链路。独立模型推理、原生模块回写与该完整面板端到端验收分别记录。

模型对照、原生工作台与性能测量使用独立证据。安装后的面板、平台实际生成及更广泛的人物／文字／织物质量仍需分别验收，不能用一个像素误差指标替代。
