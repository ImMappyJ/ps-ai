# 光影重塑工作台

中文 | [English](RELIGHT.en.md)

本指南描述开发版的结构化布光链路。现有发布包不包含此升级。原图、布光示意和模型参考图分别处理；新会话默认根据参考图估计实验光影层，“整图重绘”仍可明确选择。本地示意不预测最终合成，也不是物理精确渲染。使用步骤见[用户指南](../usage/USER_GUIDE.md#relight)，供应商协议见[后端合同](BACKEND.md)。

## 现状与能力

| 项目 | 范围 |
| --- | --- |
| 宿主 | Photoshop 27+，UXP manifest v5、API v2；TypeScript/esbuild，沿用DOM与Spectrum控件 |
| 原图 | 指定文档的可见合成图；当前选区带上下文，或明确选择整张图像；没有新增自动分割 |
| 范围 | 固定灰度蒙版 `M*(1-P)`；整图布光时全画布 `M=255`，保护区与文档坐标不由模型决定 |
| 布光控制 | 点光、聚光、平行光和全局环境光；通过语义文本表达，不是供应商的逐灯控制API |
| 原生窗口 | PS27实测大尺寸UXP dialog、PNG dataURL、绝对定位DOM标记和pointer capture拖动可用 |
| 原生操作限制 | 打开的dialog内调用既有图层回写会失败；必须关窗后短暂捕获/回写，再恢复工作台 |
| 模型 | 复用ComfyUI Qwen2.1、Bailian、Gemini、OpenAI Images；不增加服务、深度/法线/分割模型 |
| 输出 | 仅有光影层与整图重绘；新会话默认实验可编辑光影影响场，明确选择整图重绘及旧历史仍使用 NORMAL 完整结果层 |

初始容器探针使用一次性128×96合成文档。对话框内应用实际返回“建立命令不可用”，闭窗后使用既有adapter写入成功；原图身份往返49152个RGBA通道最大差0，原有文档ID和历史未变。这验证容器与短回写方案，后续工作台、性能和生成链路分别验证。

较早实现曾在 PS27 原生脚本中通过点光、聚光目标与平行光方向的实际拖动、连续手势及撤销／重做。窗口 1040×740 调整为 1160×820 后，适应比例重新计算且场景指纹不变；画外灯可找回。可拖标记保留稳定 DOM 节点和 pointer capture，静止窗口的图片加载／resize 计数停止增长，关闭后事件、预览缓存和图片引用释放。这些旧源码脚本证据不验证本次光影层、来源同步、大图路径或安装面板。

API依据：[Adobe UXP modal dialogs](https://developer.adobe.com/uxp/guides/how-to/add-modal-dialogs/)、[executeAsModal](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/executeasmodal)、[Imaging API](https://developer.adobe.com/photoshop/uxp/2022/ps_reference/media/imaging/)。dialog会阻止宿主交互；生成时可关闭编辑窗口，稍后重开恢复配置。

## 场景与坐标

入口控件 `relight-scope` 默认 `selection`；`document` 为明确的整图选择。`CaptureOptions.selection='document'` 构建全画布可编辑蒙版，不读写 Photoshop 选区；它与溶图的 `context='document', selection='edit'`、主体背景重建分别处理。整图布光不要求主体选区外存在环境，原生 16 位样本与部分灰度保护仍保留。

捕获先检查必要选区边界及处理像素预算，再允许原文件选择框出现；异步文件访问后，在捕获 modal 内重新检查来源文档和选区。缺选区使用 `selection-required` 诊断码，中英文指引建立选区或明确选择整张图像。授权期间选区或来源变化，会在建立工作副本、读取像素、上传之前停止。当前文档 ICC 始终优先；即使名称为 sRGB，显式 NONE 配置类型也不能放行。

`RelightSession` 与 `FrozenRelightSubmission` 在本地保留所选范围和输出类型，不增加供应商字段或布光场景 JSON 字段。重开保留范围与编辑，同时核对来源；允许自动刷新的条件见下文。改变范围或输出类型后，必须明确重新读取才能生成，读取失败保留原绑定并标为过期。重读保留已编辑光源，建立新的来源快照。工作台显示实际来源名称／文档 ID、冻结范围；初次产生带 ICC 的工作副本时，也显示原文档 ID。草稿和历史场景复用沿用当前明确选择的捕获策略，旧历史不需要新场景版本。

原文件授权按规范化的精确原生路径复用会话 FileEntry。可选“记住原图文件授权”在私有 `source-file-access.json` 中保存经 schema 检查的偏好与最多 32 组路径／令牌，与可迁移设置分开。令牌只来自用户选择的条目，使用 `createPersistentToken`／`getEntryForPersistentToken` 保存恢复，不使用任意 file URL 或扩大文件系统权限。开启时也保存本次已授权的条目。每次仍重新读取有大小限制的真实字节，并经 reader 和 adapter 核对路径、尺寸、原生位深，不缓存像素或颜色结论。失效授权单次操作最多回退一次选择框。令牌／存储失败保留当前可用读取，并显示不含私密路径或令牌的恢复指引。

取消记住会保留会话访问、移除已保存授权；清除按钮同时移除会话访问。偏好与清除写入排在进行中的令牌写入后，修订号阻止旧读取／旧令牌创建恢复已清除授权。移除失败必须保持可见的失败状态并保留有用的会话访问，不能宣称已删除持久授权。自动 mock 回归覆盖这些授权与范围路径；本轮有限安装流程记录在验证范围一节，持久令牌、清除／失效授权和全部范围控件仍需实机验收，合成捕获／写入检查不替代这些交互。

唯一结构化状态为版本1的 `RelightScene`，参数版本为1。来源绑定包含文档、来源图层ID、会话、历史、像素摘要、快照标识、原生尺寸、处理范围、ICC/模式/位深与蒙版引用。来源图层ID用于描述可见合成的来源，不改变实际捕获方式。图像和二进制蒙版不嵌入场景JSON，密钥不进入场景或任务历史。

每个光源有稳定ID、名称、角色、类型、启用状态、位置锁定及适用参数。最多8个光源是界面限制，不是模型精度承诺。主光/补光/轮廓光/自定义是角色，与点光/聚光/平行光类型分开。关闭灯会改变请求；隐藏标记只改变显示。

处理区域左上角为原点，x向右、y向下。x/y及聚光目标按区域宽高归一化，允许 `[-1,2]` 的画外位置。文档点为 `(bounds.left+x*width, bounds.top+y*height)`；模型坐标再映射到其内容矩形，填充属于画布变换；视口坐标还包含适应比例、缩放和平移。屏幕像素不直接传给模型，调整窗口或显示缩放不改场景。

| 参数 | 数值约定 |
| --- | --- |
| 光强 | 相对强度0–4，不是流明/照度/曝光值 |
| 相对Z | -1–1，只表达前后意图，没有恢复三维场景 |
| 范围 | 处理区域短边的0.05–3倍，仅点光/聚光生效 |
| 柔和度 | 0–1 |
| 聚光角 | 5–160度，配合目标点 |
| 平行光 | 方向-180–180度，仰角-90–90度；位置不解释为距离衰减 |
| 色温 | 2000–12000K；与自定义 `#RRGGBB` 互斥 |

全局参数包含环境光、保留原光并补光/尽量重塑、阴影强弱/柔和度、内容保持要求和用户补充。序列化值必须通过版本、类型、有限数、范围、ID唯一性和数量校验。

## 预览和请求

CPU预览只在缩略sRGB8副本上计算光照影响场，使用真实灰度编辑范围，保持Alpha。图标、名称、方向和控制手柄由DOM单独显示。它不推断遮挡、投射阴影、材质高光或物理反射；只有点击生成才发起请求。

每次来源快照准备最大边 480 和 240 的有界缓存，蒙版按可见 Alpha 贡献重采样；透明可编辑像素不能给受保护的可见内容带来编辑覆盖率。拖动复用未变化光源的几何影响图、取消过时计算，编码 PNG 前再次检查有效性。当前调度器按实际 CPU 时间预算让出执行，不假设 Canvas、WebGL、Worker 或 requestAnimationFrame 可用。

**旧预览实现的原生基线：** PS27 核心性能探针使用 4096×3072 sRGB8 与八盏混合光源：来源捕获 6606ms，缓存准备 11ms；12 次热运行的渲染／PNG 编码／图片加载算术中位数为 52.5／43／11ms，总计中位 107.5ms、nearest-rank p95 为 118ms。首次总计 152ms。这是一次核心函数基线，不是本次拖动 FPS 或所有机器的性能保证。

较早的工作台还以 4096×3072 来源、八盏灯、480×360 缓存测量 10 次真实 DOM 参数提交到新图片 load 事件：111–124ms，中位 116.5ms，p95 按 nearest-rank 取 124ms。2.513 秒静止采样期间，窗口／dialog resize 与图片 load 计数均无增长。这是旧实现的一次宿主预览更新延迟测量，不验证本次调度器、实际绘制帧率或长时间稳定性。

编译器输出稳定语义文本，先用“左上暖色主光”等自然方位、颜色、强弱描述，再保留适用数值，包含所有启用光源及全局意图。禁用灯不进入请求。编辑器实现说明和精度声明留在UI与元数据中。补充描述的明显冲突会提示；这不是完整的自然语言冲突检测。结构化状态独立保存，不能从最终提示词反向猜测灯参数。

| 后端 | 实际条件输入与几何 |
| --- | --- |
| ComfyUI | 干净source第一、可选灰度guide随后、reference最后；Qwen2.1图、保存节点8 |
| Bailian | 按source/guide/reference角色绑定，严格结果尺寸；支持能力声明内的种子 |
| Gemini | source/guide居中填入1024方形，输出反裁剪；无可配置种子，guide是视觉参考 |
| OpenAI | source/reference是images，guide转单独native mask；source/mask同变换并反裁剪；无可配置种子 |

灯坐标描述相对于未填充的源内容。不会向平台协议添加虚构的灯光、深度或法线字段。干净原图始终是主要内容依据，本地示意不替代原图。八灯精度、文字/Logo、身份与纹理保持都需检查。

任务另存提交场景、场景指纹、实际供应商/模型、净化后的能力快照、模型输入尺寸、颜色信息和结果标识。只有供应商支持时才记录真实种子；协议的占位0不代表支持种子。场景在提交时冻结，之后编辑会使旧结果出现过期提示；取消或过时请求不应成为新的成功结果，原UUID仍用于恢复。

## 可编辑光影影响场与内存限制

新会话默认使用 `lighting-layers`；旧历史未记录输出类型时仍按 `full-result` 处理。改变输出类型需要明确重新读取。一次既有模型请求提供照明参考，不增加逐灯请求或供应商字段。分析比较来源与参考的对数亮度、局部结构一致性和低频色度，尝试用来源引导滤波和增益限制减少生成纹理迁移。结构不可靠时可以拒绝提取，模型参考图仍保留，不自动改用整图重绘。这是单图保守估计：脸部、文字、边缘或材质的局部改写仍可能污染影响场，真实照片的视觉验收尚未完成。

原生写入将冻结来源合成图复制到 NORMAL 隔离组底层，随后依次按实际观测创建 Shadow/正片叠底、Cast Shadow/正片叠底、Color Atmosphere/颜色、Light/滤色、Rim Light/滤色。组与图层初始不透明度、填充均为 100%；各通道有白色可编辑蒙版，组蒙版只应用一次实际选区减保护区。无影响时 Multiply 使用白色、Screen 使用黑色、Color 使用零 Alpha。缺少可靠影响的通道不创建并记录缺失原因；完全中性的参考不会产生空光影层组。Cast Shadow 依赖稳定来源边缘沿光向下游的暗部承影区域，是二维分类，不是恢复三维遮挡。Rim Light 需要启用轮廓光且观测到边缘增亮。

实验路径仅支持已标记 sRGB 的 RGB8/16，且可编辑范围内像素全不透明。其他 ICC、灰度和可编辑透明度会明确拒绝；回填条带还会核对真实原生透明度，写入失败则回滚。可明确选择沿用原颜色／Alpha 规则的整图结果输出。底图保持文档原生位深，模型输入仍是 sRGB8。过曝或死黑丢失的细节无法恢复。发丝、皮肤、文字、Logo、织物与投影可信度需由用户实图验收。合成原生写入证据见下文；4500 万像素完整流程及这条影响场路径的真实推理仍待验收。

文档上限为 45,000,000 像素、单边 30,000。光影捕获保留原尺寸蒙版，分析图最多 1,048,576 像素／单边 1536。原生底图和影响层按最多 262,144 像素的条带顺序处理，每条带读取固定的捕获历史。512,000,000 字节的图像工作集估算包括新旧捕获重叠、分析／滤波数组、条带和面板保留缓存；这不是 Photoshop 总内存实测，也不保证所有上限内文档都能处理。不含额外面板保留缓存时，当前预算器对 9000×5000 RGB8 作用区估算 382,765,492 字节，对 RGB16 估算 399,530,984 字节，分析图均为 1373×763。以上为静态估算，不是实测峰值或原生验收。

普通原尺寸 ROI 有独立的像素与字节预算；超过它时，普通编辑和整图重绘改用带 `edit-analysis` 标记的受控工作图，不再直接因选区超过 1600 万像素而拒绝。原生蒙版按灰度保留；回填固定读取捕获历史的原生条带，只执行一次来源 Alpha 保留或背景 `min(S,A)` 重构，再写入原坐标和可编辑蒙版。候选缓存不持有每张原生蒙版，应用时按原任务重新读取。旧历史继续原行为。PNG CRC、膨胀、颜色和模型输出限制未放宽。大选区普通候选导出采用模型尺寸，背景采用工作图尺寸；提取成功的光影预览／导出／新建文档使用保存的分析尺寸，提取失败的参考图使用实际模型输出尺寸。完整分辨率需在仍有效的来源上应用后保存 PSD 或从 Photoshop 导出。

2026-10-19 在 Photoshop 27.0.0 的可丢弃合成文档中验证普通大选区：6000×4000 RGB8、9000×5000 RGB16，以及含全透明条带、半透明主体和保护区的 9000×5000 RGB8 背景用例全部通过。分析目标为 512，实际工作图分别为 627×418、686×381；原生蒙版仍为 2400 万／4500 万像素。读取／回填耗时分别为 1980／6666ms、3855／18171ms、3536／6876ms。采样处来源图层、保护区和撤销还原无差异，单步撤销、写入前取消及原生选区恢复通过；RGB16 蒙版最大差为 1／65535，可见合成最大差为 1.13／65535，两个 RGB8 用例均小于 0.46／255。可见合成比较不计 Alpha 为零处无可见意义的 RGB；来源图层另行核对。临时文档均已关闭。这是原生 API 验证，不包含 AI 推理、安装面板、完整导出或光影层实图质量，也不是峰值内存测量。

同日，3929×5893（23,153,597 像素）sRGB8 真实照片的未保存副本通过普通大选区 API 复核：1024 分析目标得到 836×1254 工作图，原生蒙版保留全部像素；读取 16022ms、回填 20109ms。逐条带遍历全图的 SHA256 验证来源图层像素不变，一次撤销和写入首条带之后取消均完整恢复合成像素、图层与历史。测试副本关闭，原文档状态保持不变。回填使用本地固定色测试图，不包含真实 AI 推理或光影质量验收。

来源观察仅在工作台打开时订阅并合并 Photoshop 文档事件，以轻量元数据核对判断失效。工作台可见或重新打开时，文档几何、ICC、范围和捕获策略仍一致，且无生成结果、活动／未确认任务及其他操作时，可以合并刷新一次改动的像素。切换文档、几何、ICC、范围或输出类型要求明确重新绑定／读取。关闭后停止观察和预览，不在后台读图，也不取消已提交任务。自动刷新失败后明确标为过期，不循环重试。重新读取始终定位绑定文档、保留灯光，并拒绝把可见的 PS-AI 输出层再次读作来源；“绑定当前文档”是单独的明确动作。旧结果保留原提交来源与导出入口，重读不会赋予新的回填许可。应用独立复验文档／会话／历史与蒙版身份。

拖动使用最大边 240 的缓存，松手提交最大边 480 的预览；标记 DOM 稳定，最多一个运行计算和一个最新等待状态。高频输入不读取 Photoshop 像素、不保存草稿、不请求 AI。指针取消、失焦及松键兜底结束交互状态；UXP 不保证派发 lostpointercapture。拖动专用的有界未压缩 PNG 避免压缩搜索，代价是较大的本地数据 URL。

## 完整结果与颜色

明确选择的“整图重绘”和旧 `full-result` 历史表示本次处理区域的完整重布光内容。图层使用 NORMAL 和可编辑蒙版，保留原始像素，支持不透明度调整和单步撤销。同次捕获重复应用只替换插件自己的候选层。来源文档关闭、历史／ICC／会话改变时拒绝回填，结果仍可导出。

原生16位来源保留为独立缓存，模型使用单独的sRGB8输入；平台输出为sRGB8，ComfyUI可选PNG16 SDR保存。它们不是HDR或原生16位模型生成。Imaging API按目标文档转换结果，未知ICC或不支持的文档模式继续明确拒绝。

半透明来源复用既有安全clipping策略，避免同一Alpha在源层与结果层重复叠加。多层来源无法验证安全底层时，应在副本合并可见层后重新读取，或导出后手工合成；不能绕过检查。
