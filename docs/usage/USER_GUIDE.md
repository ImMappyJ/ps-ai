<h1 align="center">PS-AI 使用指南</h1>
<p align="center"><strong>简体中文</strong> · <a href="USER_GUIDE.en.md">English</a> · <a href="../../README.md">返回首页</a></p>

从一次小范围修改开始：**连接后端 → 读取范围 → 描述并生成 → 检查后应用**。先[安装插件](../../README.md#安装发行包)，再按[从零配置 ComfyUI](../setup/COMFYUI.md#beginner)准备本地后端，或连接[云平台](../setup/PLATFORMS.md)。

> 本指南对应 **0.7.0 正式版**，包含新的 8 模式布局与 12 个人像／风光提示预设。用户于 2026-11-04 授权发布；本次新增预设与布局为离线验证，安装面板及真实照片效果尚未实测。此前原生 API／模型证据保留各自的验证范围。请核对版本／构建标识；历史截图与真实输出保留原说明。

本页新增的 0.7.0 创作、预设与设置图依据当前 HTML/CSS 和预设数据渲染，属于**源码界面示意，不是 Photoshop 实机录屏**。指定参考素材为 `3F3F3F.webp`。下方保留的结果、图层与布光图仍是各自注明的历史证据，不能作为新预设的真实效果验收。

本地模型按生成模型、视觉／文本编码器和 VAE 三个角色选择，不要求固定文件名或作者。0.7.0 正式版按扩展名选择 GGUF 或原生 Safetensors 加载器，仍限兼容 Qwen 2.1 架构和固定采样链；原生路线不需要 GGUF 扩展包。指定 INT8 组合已有真实推理、PNG 与小型 RGB8/16 Photoshop API 检查，完整边界见[原生实测示例](../setup/COMFYUI.md#native-tested)。面板的只读路线提示来自当前文件名；“节点已检查”只说明节点和文件名检查通过，旁边仍提示所选权重未验证。扫描／连接不会读取权重内部结构，也不会自动生成。

## 第一次编辑

1. **连接已有服务。** 启动 ComfyUI，在“设置 → 模型与连接”填写地址、扫描模型并连接。扫描保留仍可用的选择，只补全唯一匹配的预设文件；其他文件手动选。[配置工具](../setup/COMFYUI.md#environment-tools)也可从运行中的服务生成可导入设置，无需重装或重下模型。
2. **准备范围。** 在已保存的图片副本中选择“照片修图 → 局部物体／材质修改”，圈出小区域，点“预览选区”。**橙色可改，蓝色保护，灰色只供参考。**
3. **描述变化。** 例如“把金属饰件改成磨砂银色，保留原有形状”。查看候选数量、分辨率、位深和输出位置摘要；需要时展开“生成与输出”。
4. **生成并检查。** 点底部“生成候选”。生成时保持来源不变；到“结果”检查边缘、颜色、脸和文字，再“应用为新图层”，或另存 PNG。一次 Ctrl+Z 撤回一次应用。

“下一步”根据连接、来源与输入状态给出入口；导航本身不会提交生成。保护、参考和参数按需展开。切换创作／结果／历史／设置保留输入，不会停止任务；打开面板也不会自动启动后端或出图。

## 选对模式与范围

**0.7.0 布局：**三个工作区为“照片修图”“光影与素材”“生图”，共有 8 个模式。独立“场景替换”已并入“换背景”，独立“服装／道具修复”已改为局部编辑预设；角色参考移到照片修图。旧历史仍可读取和应用，复用参数时进入对应的共享模式。旧版本安装包及下面的历史截图仍可能显示旧布局。

| 工作区／模式 | 圈选什么、填写什么 |
| --- | --- |
| <a id="edit"></a><a id="costume"></a>照片修图 · 局部物体／材质修改 | 圈物体、衣物或道具，描述材质、颜色及必须保留的形状；可使用服装预设 |

### 人像与风光预设

在“场景预设”选择分类与预设，先查看选区说明和完整描述；点“使用预设”才会切换模式并替换描述。随后可自行修改，再预览选区、生成。浏览和切换界面语言不会改写已有提示词；使用时按当前语言填入。移除预设使用内置指令，保留已有描述草稿。

| 分类 | 预设 | 对应能力 |
| --- | --- | --- |
| 人像 | 服装褶皱与破损修复、服装改色（默认深海蓝）、道具表面修复 | 局部物体／材质修改 |
| 人像 | 柔灰棚拍背景、自然虚化户外背景 | 换背景，选择保留的人物 |
| 人像 | 人像融入现有环境 | 溶图，先在 Photoshop 放好人物与背景 |
| 风光 | 通透蓝天、日落暖霞、远山薄雾、秋日植被、水面反光整理 | 局部物体／材质修改，选择对应区域 |
| 风光 | 移除路人、电线与杂物 | 内置移除指令 |

#### 跟着做：衣物改色

1. 在 Photoshop 保存副本，只圈需要改色的衣物；需要精确保留的脸、手、文字先设为保护区。
2. 选“场景预设 → 人像 → 服装改色 · 深海蓝”。此时只是预览，原描述不会改变。
3. 点“使用预设”，确认任务为“局部物体／材质修改”。可把描述里的深海蓝改为其他颜色。
4. 点“预览选区”，检查橙色可改范围和蓝色保护区。边缘融合可能向外延伸；需要精确边界时关闭它。
5. 先生成 1 个候选。检查纹理、印花、人物边缘和颜色，再应用或导出。

<p align="center"><a href="../../assets/guide/070-preset-portrait-zh.png"><img src="../../assets/guide/070-preset-portrait-zh.png" width="400" alt="0.7.0 源码界面示意，不是 Photoshop 实拍"></a></p>

#### 跟着做：日落天空

1. 在自己的风光照片副本中圈天空；山脊、建筑、树枝应保留在范围外或设为保护区。
2. 选“场景预设 → 风光 → 日落暖霞”，查看说明后点“使用预设”。任务仍是局部修改。
3. 按原图修改云量、冷暖与光照描述；预览范围后生成 1 个候选。
4. 检查天空与地景是否协调，尤其是细枝和山脊接缝。该预设不会自动给地景重新布光。

<p align="center"><a href="../../assets/guide/070-preset-landscape-zh.png"><img src="../../assets/guide/070-preset-landscape-zh.png" width="400" alt="0.7.0 源码界面示意，不是 Photoshop 实拍"></a></p>

这两张图展示操作与提示词，不是新生成的效果对比；风光练习请使用有权使用的风光照片。换棚拍背景则应改为**选择要保留的人物，不要反选**。

预设不会自动建立选区、读取像素或提交生成；保留已有保护区、参考图、候选数量、模型、位深与边缘设置，请在生成前检查。天空预设只编辑选区，不会自动给整张图重新布光；普通编辑的向外渐变仍可能覆盖选区外，精确保留山脊或建筑时请使用保护区或关闭边缘融合。这里没有新增磨皮、瘦脸或身份锁定算法。预设为可编辑提示起点，离线测试不代表已通过真实人像、风光效果或安装面板验收。

要保护脸或文字，先圈出并“设为保护区”，再圈编辑范围（AI 素材默认改为圈参照主体）。保护从可改范围中扣除，羽化保留；上下文只供参考；普通编辑启用边缘融合时，额外可改范围以橙色渐变预览为准。换文档后重新准备范围；同一插件会话的原文档可从历史恢复对应选区。

**0.7.0 的边缘融合（0.6.1 包仍只支持旧版局部修图）：**“局部物体／材质修改”（含衣物预设）与“角色参考辅助”共用向外渐变蒙版，旧服装任务保留其保存的融合语义。默认按原选区短边的 15% 自动设置宽度，限制在 8–512 个原图像素；关闭自动设置后，可手动设为 0–1024，0 表示关闭融合。生成前检查范围预览中的橙色过渡。选区内部保留原覆盖，保护区最后扣除，Photoshop 原选区不变。宽渐变能缓和边界，但不能消除整张结果的偏色；“匹配未选中上下文颜色”仍是独立选项。溶图光影组／AI 重绘、光影重塑、背景及素材模式不使用此蒙版。新任务保存实际宽度和带版本的原始／有效／保护蒙版；旧历史按原公式恢复。复用参数时恢复已保存宽度，无标记旧任务为 0，并关闭自动设置。

同一会话撤销后丢失选区，可点“恢复上次选区并重新读取”：只恢复同一文档和模式的已保存范围，再读取当前像素；不会提交任务或恢复旧候选的应用资格。

**换背景／场景：**读取整张画布，自动关闭透明轮廓保留、主体对齐、颜色匹配；ComfyUI 也关闭范围辅助图。生成后检查发丝、半透明边缘与地面。明显透明的背景候选只能导出；旧记录按自己的保存范围处理。

### 让蝴蝶出现在人物周围，而不是只出现在人物里面

0.7.0 入口为 **光影与素材 → AI 素材**（0.6.0 / 0.6.1 发布包中为“人像”）。“物体与粒子”适合蝴蝶、花瓣、电弧；“光效与氛围”适合光雾、烟尘。它们是提示预设，不是两个不同模型。

1. 在 Photoshop **选中人物主体**，使用默认的“参考主体 · 独立放置”。
2. 将活动范围设为“主体周围的矩形区域”，调节扩展比例（默认 50%），或明确选择“整张画布”。当前不支持另画一个任意形状的活动区。
3. 选择关系：**前景叠加**可显示在主体内外；**主体遮挡**从素材范围扣掉主体，不会把素材真的移到原图层下。想要前后穿插，需分别生成／手工分层，不自动判断立体环绕。
4. 点“读取主体并预览活动范围”。从左到右检查来源图、主体参照、实际放置图。**最后一张白色区域才是素材允许出现的位置**；保护区也会扣除。
5. 描述例如“几只蓝色发光蝴蝶分布在人物肩膀两侧和头部周围，大小有变化”，生成后先看“仅素材”，再切“叠加预览”。发现残留人物、底色或辅助线时，不要应用。
6. 应用得到带可编辑蒙版的独立素材图层，不重绘或替换原图层。素材 alpha 保留，放置蒙版只应用一次；完全不透明输出保留导出但禁止回填。

叠加预览使用保存的来源，只显示捕获区域，最长边 1280px，不是原生全尺寸验收。另存 PNG／新文档仍是**原始素材**，不混入来源或烘焙放置蒙版。额外角色参考不参与；“新文档”不等于纯文字。旧“参考当前图片与选区”仍可明确选择，保持选区内放置；旧历史也保留原范围，不自动扩大。“仅文字生成独立素材”不读取当前图片。

新主体方式发送 3 张图，平台必须明确声明支持；旧中转或不支持的模型会在上传前拒绝，不静默降级。更新插件时也更新配套中转。ComfyUI、百炼 Qwen 2.1 和 OpenAI Images 的协议已有离线覆盖；Gemini 不支持此透明素材路径。

旧双图图片参考在实际 Qwen 样本中仍残留人物、背景或辅助边界，**未通过视觉验收**。新三图主体方式修正的是输入、范围和回填逻辑，尚无真实模型质量或安装面板验收；不能保证模型只返回干净的蝴蝶。透明像素不是分离成功的证明，插件不会自动抠图、原图相减或重发。下方素材案例仍是纯文字输出后的手工定位合成，不是新路径效果图；现有截图也不展示新素材控件。

## 给画面重新布光

1. 选择“光影与素材 → 光影重塑”（旧版为“人像”），确定“当前选区”或“整张图像”；需要地面投影就把地面也纳入范围。
2. 打开工作台，核对当前合成图。更换背景或文档后点“重新读取当前文档”；已编辑灯光保留。透明抠图可先在副本下加入背景，确保作用范围不透明。
3. 添加、拖动和调整灯光，最多八盏；可复制、禁用、锁定。布光示意仅表达意图，拖动、工作台撤销和隐藏标记都不会生成图片。
4. 明确点击“生成 AI 结果”，检查后应用或导出。生成后修改灯光，旧结果会提示过期。

<p align="center"><a href="../../assets/guide/050-relight-zh.png"><img src="../../assets/guide/050-relight-zh.png" width="800" alt="光影重塑工作台，画布显示本地布光示意"></a></p>

| 输出／参数 | 用法 |
| --- | --- |
| 光影层（默认） | 从 AI 参考估计光照，叠加在原图上，应用为有蒙版的穿透组，不复制底图 |
| 整图重绘 | 采用模型生成的图片，结构和纹理可能变化，应用为蒙版图层 |
| 光效还原 | 0–1，默认 1；降低减弱效果，0 回到原图 |
| 细节保护 | 0–1，默认 0.65；提高减少细碎变化，也会柔化局部阴影 |

候选的两项参数在松开滑块／确认数值后本地重算，随候选保存，**不用重新生成**。组不透明度也可调整；下方原图改变内容或位置后，旧光影可能不再匹配。

当前源码中的光影方式支持已标记的 RGB 8/16 位原文档，作用范围必须不透明。非 sRGB 来源须通过实际 ICC 的读取和转换检查；光影组在原文档色彩空间中计算、应用，原图层和配置文件保持不变。旧的非 sRGB 历史任务没有保存所需的原生色彩数据，需重新读取生成。显式选择 AI 重绘仍使用原有流程；非 sRGB 重绘任务如需改用光影组，应选择光影方式后重新读取生成。灰度、CMYK、Lab、32 位 HDR 和无法验证的 ICC 仍不支持光影组。

模型输入仍为 sRGB8，会损失部分色域和精度。光影方式保留原图作为内容基础，但无法完全分离光照和重绘：大幅错位会留下光斑，硬阴影和细窄轮廓光可能减弱。原始 AI 参考可单独导出，不会自动改成整图重绘。原 ICC 扩展已通过 Photoshop 27 的 sRGB、Adobe RGB、ProPhoto RGB 和已安装 image P3 配置文件的 8/16 位合成样本 API 检查，覆盖应用与撤销；安装后面板操作、真实推理及照片效果仍需分别验收。已发布 0.6.1 的限制以对应版本为准。

读取失败时保留灯光与旧候选，不能拿旧来源继续新任务。任务内重开显示该任务绑定的来源。读写时工作台可能短暂关闭再恢复；关工作台不等于取消，请用任务取消按钮。

## 让主体融入背景

1. 先将人物／物体放入背景，选中前景主体；不要全选画布，单独透明抠图没有可参考的环境。
2. 读取当前图片与选区，按需设保护区，描述“匹配左侧窗户暖光”等要求，再生成。
3. 比较原图、融合预览与 AI 参考；检查主体、边缘和细节后应用。背景供参考，回填只改主体减去保护区。

0.7.0 新任务默认“保留细节 · 只应用光影”，生成不含底图副本的光影组；光效还原和细节保护可本地调整，不再次提交。也可明确选择“AI 重绘主体”；旧历史保持其原方式。光影来源要求同布光，不符合时不会自动换方法。

溶图读取整张合成图，自动关闭主体对齐与上下文颜色匹配；ComfyUI 不发灰度辅助图。AI 参考变化弱时，本地算法无法凭空补光；真人结果可能偏弱，光斑和阴影仍需检查。下方旧版溶图案例是 **AI 重绘**，不是新增光影提取的验收图。

大图溶图会在读取前计算来源、原尺寸蒙版、候选及已有预览的内存需求，必要时自动降低**分析工作图**尺寸。原图、原尺寸蒙版和请求的生成分辨率保持不变；来源说明会列出各尺寸，较低分析尺寸可能平滑细小光影。历史重载与光影重处理沿用保存的分析尺寸。这三种编辑模式启用边缘融合后也会提前核算候选校验缓存，必要时改用受控工作图和原尺寸分条回填。512 MB 插件工作预算和文档上限仍保留；极端分辨率／位深组合或已有缓存过多时仍会在上传前拒绝，可降低生成分辨率后重试。此估算不代表 Photoshop 总内存或显存占用，也不扩展光影的色彩空间支持。

## 历史、断线和取消

| 操作 | 会发生什么 |
| --- | --- |
| 点击记录／勾选记录 | 点击查看详情，勾选用于批量清理；每页 20 条，全选覆盖当前筛选的所有页 |
| 读取候选 | 读取本地结果，不生成；应用资格仍由原来源决定 |
| 恢复此历史选区 | 在本次插件会话的原文档中恢复该记录的原选区与保护区，保留当前参数 |
| 复用参数与选区 | 恢复描述、设置与保存的范围，读取当前像素；检查预览、重新选择参考图后再生成 |
| 恢复任务 | 先切回原后端类型与地址，再查询保存的原 UUID，不重复提交 |
| 取消 | 取消当前任务并停止后续候选；云端已开始的请求仍可能完成和计费 |
| 清除勾选历史 | 二次确认后清除本地记录与插件候选文件；保留 PS 文档、图层、导出、设置和灯光草稿 |

未确认任务持续显示提醒。连续状态读取失败后保留未知和原 ID，稍后可恢复；未知不等于远端失败。仅未知任务可二次确认“停止本地跟踪”，它不取消远端、不停止计费，重新生成可能重复执行。清历史也不取消任务或清后端；中断清理可“重试本地清理”。

**0.7.0 的历史选区复用（已发布的 0.6.1 包尚未包含）：** 新捕获任务各自保存原生选区、羽化与保护区，浏览历史本身不改动选区。整图布光保留整画布范围，不创建额外 PS 选区。没有可靠原始范围的旧记录仍可复用参数和导出；换了文档或插件会话时需要重新圈选。清除历史时一并清除对应蒙版数据。

取消或改变选区后，如果旧候选显示“**检查来源**”，点击后会按原生位深和 ICC 核对整张文档与仍可读取的 Photoshop 历史基准。通过后再点击应用；候选使用自己保存的有效蒙版，不依赖当前选区。真实像素变化、历史基准丢失、关闭重开文档或插件会话结束时仍拒绝应用，可在允许的原文档上复用范围重新生成，或导出旧候选。不会自动倒退文档历史或重新推理。该路径已通过 Photoshop 27 的独立 sRGB8、ProPhoto RGB16 和透明合成测试，覆盖灰度羽化、保护、已有候选图层替换与一次撤销；安装后面板操作和真实照片效果仍需分别验收。

## 色彩、位深与原稿

优先使用 **Photoshop 当前文档 ICC**，包括打开时已有的转换；导入图层的原文件不能代表整个合成图。读取当前文档不会另开原文件选择器。有精确已授权文件时可核对可靠声明；未标记 RGB8/16 仍无法确认时，自动创建保留图层、位深与范围的独立 sRGB 副本，原文档保留。

“**假定 sRGB**”表示近似，可能偏色，不是找回原 ICC。提示随同一会话重读和保存候选保留；应用只绑定该工作副本。参考图默认仍需当前 ICC 或所选精确文件的可靠声明。

**0.7.0 参考图读取：** 对于没有配置文件的 RGB8/16 网络参考图，可勾选“本次参考图无配置时按 sRGB 近似读取”再选图。它只在临时副本中解释颜色，原文件和已打开原图不变；已有可用 ICC 或可靠声明时仍优先使用它们。选项每次选图后自动关闭，取消或失败也会关闭。实际用了近似时，参考图旁、生成结果和任务历史都会显示“假定 sRGB”。重用历史参数不会恢复此选项。需要准确颜色时，请在副本中核对并嵌入正确 ICC 后导入；近似不能证明原图本来就是 sRGB。

多次撤销使已知工作副本丢失标签时，仅本次会话仍可核对的来源提供“创建已恢复色彩副本并重新读取”。它保留旧文档与重做历史，创建新来源；旧候选不因此获得新应用资格。没有入口时手动核对副本色彩。旧文件授权管理在“设置 → 文件授权与隐私”，不属于日常读取步骤。

模型与参考输入均为 sRGB8，会损失宽色域和精度；[可选 SDR16](../setup/COMFYUI.md#output-depth)不是原生 16 位生成或 HDR，平台目前输出 sRGB8。回填 8 位文档会降为 8 位，不自动转换原稿。

## 遇到问题

| 情况 | 下一步 |
| --- | --- |
| 缺选区或全被保护 | 重新圈选／清保护，布光也可明确选整图 |
| 工作台仍是旧图 | 重新读取并检查成功；任务内重开保留原任务来源 |
| 半透明多层无法安全应用 | 在副本合并可见层后重新生成，或导出手工合成 |
| 来源已变，不能应用 | 导出旧候选，重新读取当前图开始新任务 |
| 连接、模型或位深错误 | 展开技术详情，对照 [ComfyUI 配置](../setup/COMFYUI.md) |
| 宿主退出 | 保存工作、记录复现与脱敏错误；换安装方式不能保证解决 |

文档上限 4500 万像素、单边 30000；不支持 CMYK、Lab、索引色、多通道、32 位 HDR 或未知色彩的灰度。角色参考、光影、溶图和素材均需逐图检查，云平台真实 Key 出图仍待验证。许可与数据发送说明见[首页](../../README.md#使用前了解)。

“设置 → 宿主诊断 → 图像往返验证”会写入测试文档并检查范围、蒙版、撤销和回滚；先保存工作，分享报告前检查隐私。技术边界见[后端契约](../development/BACKEND.md)与[布光实现](../development/RELIGHT.md)。

0.7.0 的报错框提供“**关闭错误提示**”按钮。关闭只隐藏该报告，不删除任务或历史，也不取消运行。相关操作成功重试后会清除已解决的错误；无关操作或较早的异步结果不会清掉新错误。取消参考图选择不算导入成功。
