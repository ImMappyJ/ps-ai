<h1 align="center">PS-AI 使用指南</h1>

适用 **0.5.0 实验版**。先[安装插件](../../README.md#安装发行包)，再连接[ComfyUI](../setup/COMFYUI.md)或[云平台](../setup/PLATFORMS.md)。界面图来自 Photoshop 27；各模式另附真实生成结果，演示图片为 `3F3F3F.webp`。配置图与布光示意不代表模型效果。点击图片可看大图。

## 先认识面板

| 页面 | 用来做什么 |
| --- | --- |
| 创作 | 选择模式、填写要求、预览选区、生成候选 |
| 结果 | 比较候选、查看细节、应用图层或导出 |
| 历史 | 查看本地记录、读取旧候选、复用参数、恢复任务 |
| 设置 | 配置后端与模型、切换语言、导入导出设置、运行诊断 |

切换页面不会停止任务，也不会丢掉正在编辑的描述和参数。面板不会在打开时自动启动后端或生成图片。

![创作面板与演示图片](../../assets/guide/050-create-zh.png)

## 完成第一次编辑

1. 在“设置 → 模型与连接”配置后端，保存后点“连接”。已有 ComfyUI 可直接使用，不用重装；云平台需要自己的 Key。
2. 在 Photoshop 打开已保存的图片副本，回到“创作 → 局部修图”。
3. 选择“局部物体／材质修改”，圈选要改的位置。要保护脸、文字等细节，先圈出它们并“设为保护区”，再重新圈选编辑范围。
4. 输入要求，例如“把金属饰件改成磨砂银色，保留原有形状”。点“预览选区”：**橙色可改，蓝色受保护，灰色只供参考**。
5. 点“生成候选”，等待结果。生成时不要修改来源文档；断线后使用“恢复任务”，不要重复提交。
6. 在“结果”检查细节，点“应用为新图层”。原图层保留，结果带可编辑蒙版，可调不透明度或按一次 Ctrl+Z 撤销。

![模型与连接设置](../../assets/guide/050-settings-zh.png)

![英文设置界面](../../assets/guide/050-settings-en.png)

设置 JSON 可迁移地址、模型和语言，不含 Key、模型文件或图片历史。CCX 与 Portable 的数据分别保存。

## 选区怎么选

| 模式 | 选什么 |
| --- | --- |
| 局部修改、移除、服装、角色参考 | 要修改的区域 |
| 换背景、场景替换 | **要保留的主体，无需反选** |
| 溶图 | 已放入背景中的前景主体，主体外需有可见环境 |
| 光影重塑 | 当前选区，或明确选择“整张图像” |
| 图片参考特效／氛围 | 素材应出现的位置 |
| 文字生图、纯文字素材 | 默认不需要来源选区；应用到当前选区时需先圈选 |

上下文只供模型理解画面，不会扩大实际回填范围。保护区会从编辑范围中扣除，羽化保留。换文档或复用旧参数后，请重新准备选区与保护区。

撤销后选区丢失时，可重新圈选，或在同一文档、同一模式点击“恢复上次选区并重新读取”。它只恢复本次会话保存的范围，再读取当前图片；不会提交任务，也不会恢复旧候选的应用权限。

透明抠图要做整图布光时，可先在副本下方加入背景，让作用范围内没有透明像素。演示副本保留原图和背景两层：

### 3. 换背景

入口：**局部修图 → 换背景（选择主体）**。

1. 选中要保留的人物或物体，不要反选。
2. 描述新的场景、地面和灯光，例如“浅紫色摄影棚，柔和侧光，简洁地面”。
3. 预览主体边缘与保护区，再生成。检查发丝、半透明边缘和地面衔接后应用。

此模式读取整张画布，自动关闭透明轮廓保留、主体对齐和颜色匹配；ComfyUI 也会关闭范围辅助图。离开后恢复普通编辑偏好。背景仍明显透明的候选只能导出检查，不能应用。旧候选继续使用它保存的范围，不会自动反转蒙版。

实测：“浅蓝色摄影棚，柔和侧光，简洁地面，人物脚下有自然接触阴影”。选中主体保留，让透明背景变成完整场景。

入口：**人像 → 角色参考辅助**。

### 7. 特效素材

入口：**人像 → 特效素材**。

默认“参考当前图片与选区”：圈选素材放置位置，预览来源与灰度范围，再描述形态、方向和颜色，例如“手边的蓝色弧形光带”。只想生成独立素材时，改选“仅文字生成独立素材”。

应用位置与输入方式分别选择：“新文档”不会自动改成纯文字。图片模式不使用额外角色参考。回填保留素材自身透明度，并用保存的选区减去保护区作为蒙版；完全不透明的输出只能导出。

**当前图片参考素材效果尚未达标**：实际 Qwen 样本可能残留人物、场景或范围边界。请先检查透明度和残留，不要把有透明像素当成可用素材。

可用路径示例：用“仅文字生成独立素材”生成蓝色弧形闪电，再手工缩放、定位到测试图的卧室副本。三栏为来源、透明素材、叠加预览；这不是图片参考模式的成功样本。

<a id="relight"></a>

### 10. 光影重塑

入口：**人像 → 光影重塑**。

1. 选择“当前选区”或“整张图像”。需要地面投影时，把地面也包含在作用范围中。
2. 打开工作台，核对原图。空闲时打开和“重新读取当前文档”都会读取 Photoshop 当前活动文档的可见合成图，包括新背景和合并后的图层；已编辑的灯光保留。
3. 添加或拖动光源，调整类型、角色、强度、颜色与方向。最多八盏灯，可复制、禁用、锁定或删除；“隐藏标记”只隐藏辅助线。
4. 在“布光示意”看大致范围和冷暖，再选择输出，点“生成 AI 结果”。拖动、输入或工作台撤销都不会提交模型请求，一次拖动算一步撤销。
5. 检查 AI 结果，再应用或导出。生成后改了灯光，旧结果会提示过期。

![光影重塑工作台，本地布光示意](../../assets/guide/050-relight-zh.png)

| 输出 | 区别 |
| --- | --- |
| 光影层（默认） | 从 AI 参考图提取光照变化，叠加在原生来源底图上，应用为带蒙版的图层组。各通道可继续调整。 |
| 整图重绘 | 使用模型生成的图片，应用为带蒙版的新图层；结构和纹理可能变化。 |

**布光示意只表达意图，不是最终效果。** 光影层优先提取柔和的整体明暗和色调，平滑光影变化，保留原图作为内容基础。它不再因结构相似度不足而停止，但大幅错位仍可能产生光斑，硬阴影和细窄轮廓光也可能减弱。来源须为有标签的 sRGB RGB 8/16 位，且作用范围内像素不透明。原始 AI 参考仍可单独导出；不会自动改成整图重绘或重新生成。

旧版失败记录：下图右侧的真实 AI 参考曾因人物结构和纹理变化触发旧版拦截，当时没有作为光影层应用。当前版本已移除相似度拦截；可从历史读取已保存的候选重新提取，无需再次生成。下图不代表新算法的效果。

![3F3F3F 光影提取失败示例：左为来源，右为未应用的 AI 参考](../../assets/guide/050-result-relight.png)

从主面板打开时若读取失败，工作台保持关闭，并保留灯光与旧候选。已经打开的工作台重读失败会显示旧图失效原因。读成功后，对应的旧读取错误会消失。生成／应用后的内部重开保留原任务来源；已有候选始终绑定它提交时的快照。

工作台在读取或回写时会短暂关闭再恢复。关闭工作台不等于取消任务；取消请用任务按钮。

<a id="blend"></a>

### 11. 溶图

入口：**人像 → 溶图**。

1. 先把人物或物体放进背景，再选中前景主体。不要全选画布，透明抠图本身没有可匹配的环境。
2. 预览范围，直接生成，或补充“匹配左侧窗户暖光，保留面部结构和衣服纹理”等要求。
3. 检查主体光线、色温、边缘与画风，再应用。背景供参考，回填只改主体减去保护区。

溶图读取整张合成图，自动关闭主体对齐和颜色匹配；ComfyUI 不发送灰度范围辅助图。真实插画样本已有明显明暗变化，真人样本仍可能变化较弱。它不是精确调光，也不保证脸和纹理完全不变。

实测：测试图先放入舞台背景，再为主体匹配环境光。右侧人物明显变暗，背景按保存的选区保留；脸部与衣服细节也有变化，需要检查。

## 比较、应用和导出

- **候选**：每批 1–4 张，依次生成；锁定种子时逐张递增。点缩略图切换，用“100% 查看”检查细节。
- **应用**：先新增蒙版图层；同次捕获切换候选后可“替换本轮候选图层”。光影层输出应用为组。
- **撤销**：一次 Ctrl+Z 撤回一次应用。不透明度调整单独记入历史；PS 撤销后面板滑块不会实时同步。
- **导出**：“另存 PNG”保存候选，“新文档查看”打开独立 sRGB 文档。导出可能是工作图／分析图尺寸；要交付原尺寸，请应用到来源后通过 Photoshop 保存或导出。

下图是从历史读取的候选。来源属于此前会话，仍可导出，不能直接应用。

![从历史读取的结果页](../../assets/guide/050-results-zh.png)

生成期间不要修改来源。来源改变、关闭或来自旧插件会话时，候选仍可导出；“检查来源”会说明无法应用的原因，不会修改文档。

## 历史和任务恢复

点击记录查看详情，勾选框用于批量清除，两者独立。每页 20 条，可按“全部／未确认”筛选；“全选”包含当前筛选的所有页。窄面板可进入详情后再“返回历史”。

![历史详情与候选预览](../../assets/guide/050-history-zh.png)

- **读取候选**：打开已保存的结果，不重新生成。应用资格按该候选自己的来源判断。
- **复用参数**：恢复描述和设置；选区、保护区和参考图需重新准备。
- **恢复任务**：在保存的后端查询原 UUID。请先切回原后端类型和地址，不要重复提交。
- **取消**：处理中的按钮只取消当前任务并停止后续候选。云端已经开始的请求仍可能完成并计费。

未确认任务会持续显示提醒。连续查询失败后会保留原 ID 和未知状态，可稍后恢复；未知不等于远端失败。仅未知状态可经二次确认“停止本地跟踪”，它不取消远端任务、不停计费，再生成可能造成重复执行。

“清除勾选历史”经确认后删除对应的本地记录和插件候选文件，保留 PS 文档、已应用图层、导出的图片、设置和布光草稿。它也不删除后端数据或取消任务。中断后按“重试本地清理”处理残留。

## 参数怎么调

![进阶参数](../../assets/guide/050-advanced-zh.png)

| 参数 | 建议 |
| --- | --- |
| 分辨率 | 常用 768、992、1024；编辑按原比例调整，模型能力依后端而定 |
| 步数 | 默认 25，可设 1–100；增加步数不保证更好 |
| 上下文边距 | 默认 15%，只增加参考环境；背景、场景与溶图读取整张画布 |
| 范围辅助图 | 给模型的视觉参考，最终限制由 PS 蒙版完成；部分模式自动关闭 |
| 保留原透明轮廓 | 适合衣物、材质修改；移除或扩展轮廓时按需关闭 |
| 对齐透明主体 | 按透明边界调整位置和大小，可能影响比例 |
| 颜色匹配 | 只修正小幅整体偏色；不用于抵消有意的布光或溶图变化 |

<a id="source-color"></a>

## 色彩与位深

支持色彩空间明确的 RGB／灰度 8/16 位。已有文档 ICC 优先保留；无 ICC 的静态 WebP 或显式 sRGB PNG，在授权核对原文件后可建立保留图层的 sRGB 工作副本。无法确认时，请在副本中指定正确配置文件，不要随意猜成 sRGB。

多次撤销导致工作副本失去色彩标签时，若本次会话仍能核对记录，会出现“创建已恢复色彩副本并重新读取”。它创建新副本，保留旧文档和重做历史；旧候选不会因此获得新来源的应用权限。没有恢复入口时，请手动核对副本色彩。

模型输入和参考图使用 sRGB8。ComfyUI 可选 SDR16 保存，需要[专用节点](../setup/COMFYUI.md#output-depth)；平台当前输出 sRGB8。16 位来源和文件不等于模型原生 16 位精度，也不代表 HDR。写入 8 位文档会降为 8 位，不自动转换原稿。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 没有选区，或编辑区被全部保护 | 重新圈选、清除不需要的保护区；布光也可选“整张图像” |
| 工作台还是旧图 | 点“重新读取当前文档”，检查是否成功；生成期间重开显示的是该任务的来源 |
| 光影提取停止 | 检查保存的 AI 参考图与原图结构；可导出参考，或明确选择整图重绘，不会自动重提任务 |
| 背景仍是透明或黑色 | 确认选择的是要保留的主体，并描述具体场景；旧候选不会因切模式而重新生成 |
| 半透明多层无法安全回填 | 在副本中合并可见层后重新生成，或导出后手工合成 |
| 来源改变，不能应用 | 保留或导出旧候选，重新读取当前图片后开始新任务 |
| 连接、模型或位深报错 | 核对[ComfyUI 配置](../setup/COMFYUI.md)，展开“技术详情”查看原因 |
| 成功后仍看到报错 | 成功重试会清除对应的旧错误；历史失败记录和其他任务错误仍保留 |
| Photoshop 退出 | 先保存工作，记录复现步骤与日志；更换安装方式不能保证解决宿主崩溃 |

文档上限为 4500 万像素、单边 30000，不是模型原生生成分辨率。CMYK、Lab、索引色、多通道和 32 位 HDR 不支持。角色参考、光影层、溶图和素材效果仍需逐图检查；云平台真实 Key 出图尚未测试。

“设置 → 宿主诊断 → 图像往返验证”会在测试文档中检查选区、蒙版、撤销和回滚，可保存报告。分享前检查图片、提示词和路径隐私。技术契约及验证范围见[开发文档](../development/BACKEND.md)与[布光实现](../development/RELIGHT.md)。
