<h1 align="center">PS-AI 使用说明</h1>
<p align="center"><strong>简体中文</strong> · <a href="USER_GUIDE.en.md">English</a></p>

这份指南使用同一张 **3F3F3F.webp** 的独立副本演示九种模式。截图来自 Windows Photoshop 27.0 中的实际 Portable 面板；结果图来自 Photoshop 合成后的像素。点击图片可看原始 PNG，面板截图保留 541 像素宽，没有放大补画。

**对应版本：0.4.0（实验版）。** 0.3.0 不包含配置向导、范围预览和可选 16 位输出。安装见 [README](../../README.md#安装发行包)，后端与模型见 [ComfyUI 配置](../setup/COMFYUI.md)。

以下截图与九种模式验收使用 ComfyUI。平台适配的配置和限制见 [百炼](../providers/BAILIAN.md)、[Gemini / Nano Banana](../providers/GEMINI.md) 与 [OpenAI Images](../providers/OPENAI.md)；这些平台路径尚未完成真图和宿主验收，不能套用下面的已测结果。

开发版把原 **COSPLAY** 分类改为“人像”，增加“光影重塑”和“溶图”，共十一种模式；移除杂物无需填写提示词，换背景与场景替换改为选择主体。下面九种图例仍是 v0.4.0 的实测记录，不能验证新增交互或效果。新版四个平台与 Key 操作见 [平台配置](../setup/PLATFORMS.md)。

## 开发版界面导航

开发版将原来的纵向长页面分为以下区域。导航只切换显示，保留当前模式、提示词、参考图、参数、任务和候选；生成、应用、恢复仍需明确点击。

| 位置 | 内容 |
| --- | --- |
| 创作 | 局部修图／人像／生图、任务模式、输入描述、选区与保护区、参考图、应用位置、生成参数与输出位深。专业参数保留在“进阶参数”中。 |
| 结果 | 当前候选及编号、放大的显示预览、来源与可应用状态、100% 查看、另存 PNG、新文档查看和已应用图层不透明度。 |
| 历史 | 可选中行的记录表格，包含全部／未确认筛选、分页、读取候选、复用参数和恢复入口。复用布光仍须明确绑定当前原图。 |
| 设置 | 模型与连接、语言、API Key、配置导入／导出、配置向导和宿主诊断。 |

底部显示当前操作与任务状态；切换页面不会停止任务。应用按钮仍区分“应用为新图层”和“替换本轮候选图层”，失效来源或不安全候选保留导出路径。错误说明包含影响与下一步，技术详情可展开复制。

光影重塑从“创作 → 人像 → 光影重塑”进入独立布光工作台。其工具栏、光源列表与参数区使用同一视觉样式；原图、布光示意和 AI 结果仍有独立入口。“隐藏标记”只影响显示，“启用此光源”仍决定该光源是否参与布光。

显示预览独立于候选与导出像素，预览清晰度和布局调整不会改写结果。模式、参数默认值、场景格式、图层与撤销规则保持原有语义。下方 v0.4.0 截图仍是旧面板记录；新布局在安装面板中的停靠、系统缩放及完整宿主流程需要单独验收。

## 先连接，再准备副本

1. 启动 ComfyUI，在浏览器确认地址可以打开。
2. 从 Photoshop 的“增效工具”打开 PS-AI，Portable 入口是 **PS-AI (Portable)**。
3. 展开“模型与连接”（开发版先打开“设置”），填写完整地址，例如 `http://localhost:8188`。可以改主机和端口；不要填账号、路径或查询参数。
4. 点“扫描模型”，选择配套的 Qwen 2.1 生成模型、视觉／文本编码器和 VAE，再点“保存配置”“连接”。其他架构不能只改文件名就接入。
5. 初次可按“配置向导”测试地址、检查环境、运行生成示例。最后一步使用后端，在独立测试文档中生成并应用图片。
6. 打开样图并先存 PSD 副本。开发版新增：[10 · 光影重塑](#relight)、[11 · 溶图](#blend)。

每个例子都从原图重新复制，避免前一轮修改影响下一轮。

语言和输出位深切换后保存；地址和模型需点“保存配置”。导出／导入 JSON 可以迁移设置，不包含模型权重和图片历史。CCX 与 Portable 的数据各自独立。

来源要有正确 ICC，支持已标记的 RGB／灰度 8/16 位。未标记图片会被拦截；CMYK、Lab、索引色、位图、多通道、32 位 HDR 请先准备 RGB 副本。本例原 WebP 是 8 位，副本转为 **RGB / 16 位、sRGB IEC61966-2.1** 验证回填；转换不会补回原图没有的细节。

<a id="source-color"></a>

**开发版读取原图色彩：** 当前文档已有 ICC（包括 Adobe RGB）时，保留当前颜色解释，不需要选择原文件。没有 ICC 且有原文件的 RGB 图片，需要授权读取该原文件；出现选择框时，选择正在编辑的原文件，例如 `3F3F3F.webp`。插件核对路径、尺寸、位深，再读取颜色声明：无 ICC 的静态 WebP 按规范使用 sRGB，PNG 则需要明确的 sRGB 标记。识别成功后会打开一个保留图层的 sRGB 工作副本，预览信息显示采用的规则，生成和“应用为新图层”都面向该副本。原文档不修改，当前未保存的图层也会保留。新增的未标记内容同样按原文件的色彩空间解释；如果之前按其他工作空间调过颜色，请检查副本外观。先前设置的保护区会随坐标一起带到副本；之后继续在这个副本上圈选和生成。

已授权的文件在本次插件会话中复用。**进阶参数 → 记住原图文件授权**默认关闭；开启后在插件私有存储中保存最多 32 个精确文件授权令牌，宿主支持时也会保存本次会话中已经授权的文件。授权和此偏好不随配置、任务历史或诊断日志导出，不保存像素或颜色结论；每次仍读取有大小限制的实际字节并检查颜色声明，同路径文件被替换也不能复用旧的 sRGB 结论。授权失效、文件移动或无法读取时，单次操作最多再打开一次选择框，请重新选择原图。宿主不支持持久令牌或私有存储不可用时，当前已授权读取仍可继续；请查看授权状态中的恢复指引。

取消勾选会移除保存的授权，本次会话访问仍可使用；**清除原图文件授权**还会移除会话授权，以后需要时重新选择原图。私有存储更新失败时，面板会明确报告清除失败并保留可用的会话访问；检查存储并重试清除，不要把失败提示当作已删除。已有有效 ICC 的工作副本不需要重新选择原图。授权缓存与新控件有 mock 覆盖，安装后 Photoshop 行为仍待验收。

如果取消选择、选错文件、原图超过 64 MB、没有可核对的原文件，或色彩信息无法确认，会停止捕获，不会上传此范围。此时请确认真实色彩空间，在副本中使用“编辑 → 指定配置文件”，再重新捕获。开发版已在 Photoshop 27 读取本例 WebP，并在独立无 ICC 副本上验证工作副本捕获、等值回填（像素差为 0）、一次撤销和清理，原文档保持不变。PNG、参考导入及新版面板交互仍待实机验收；已发布 v0.4.0 仍按上段要求准备带 ICC 的副本。

后续开发修正把工作副本的 sRGB 指定保存为独立历史基线，避免应用候选后一次 Ctrl+Z 同时丢失颜色解释、再次捕获时因副本没有原文件路径而失败。此撤销重捕获修正有 mock 回归，仍需新构建的 Photoshop 验收。旧版本已失去 ICC 的无路径副本不会自动猜成 sRGB；请确认正确配置文件并手动指定，或回到原图重新捕获。主动改色、移除配置、关闭或重开文档后仍会检查来源，旧候选可导出。

## 本例统一参数

**候选 1 张、分辨率 992、25 步、锁定种子 42、上下文边距 15%、关闭颜色匹配、16-bit SDR 输出。** 使用兼容清单中的 Qwen 2.1 Q4_K_M、Qwen3-VL INT8 和 Qwen 2.1 VAE。编辑候选按来源长宽比生成，不一定是正方形。精确提示词、开关和实际尺寸见 [示例参数 JSON](../../assets/guide/recipes.json)。

没有配置 16 位保存节点时，保持默认 **8-bit（兼容）** 即可。切换 16-bit SDR 前，按 [后端指南](../setup/COMFYUI.md) 安装 `PS_AISavePNG16` 并重启 ComfyUI。网页预览为 8 位，不能用于判断 16 位文件精度。

## 选区编辑的共同步骤

开发版在 Photoshop 撤销到较早状态后，选区也可能消失。可以重新圈选后点“预览选区”，或在原模式明确点击“恢复上次选区并重新读取”。后者用本次插件会话最近一次成功捕获的范围替换 Photoshop 选区，保留规范化后的 8 位灰度羽化和原坐标；背景／场景模式恢复要保留的主体。它只用于同一来源文档、尺寸、原生模式／位深和面板模式；重载插件或跨会话需重新圈选。此操作只恢复范围，随后读取当前像素和颜色信息，扣除当前保护区一次并显示新预览。检查后再点“生成候选”；恢复不会提交任务，也不会让旧候选越过文档历史检查。重新读取失败时，已恢复的选区保留，旧来源像素不再用于提交。

“设置 → 构建”显示版本和源码短修订号；`-dirty` 表示包含未提交修改的构建，未打包的源码运行显示 `dev (unbuilt)`。可复制的报错技术详情也包含该标识，用于区分版本号相同的构建。选区恢复与这些控件有离线回归覆盖，安装后 Photoshop 行为和撤销仍需原生验收。

选中范围后点“预览选区”：**橙色可编辑，蓝色为手动保护，灰色只提供上下文**。生成时重新捕获。要保护脸或手，先选中它们“设为保护区”，再重新圈选编辑区。换文档或恢复旧参数后要重新设保护区。

点“生成候选”，等进度结束，检查缩略图和“100% 查看”，再“应用为新图层”。结果带可编辑蒙版，来源图层保留。下文橙色图根据实际蒙版制作，是范围示意；面板截图单独展示。对比图均为左侧原图、右侧结果。

<a id="background-fix"></a>

**开发版的背景替换：** “局部修图 → 换背景”和“人像 → 场景替换”都先选择要保留的主体，无需反选。插件读取整张画布，结合主体选区和原始透明度计算背景回填范围，覆盖主体选区外的透明画布，并处理半透明边缘与新背景的融合。先预览范围，检查不透明主体核心和手工保护区是否排除。两种模式自动关闭“保留原透明轮廓”“对齐透明主体”和“颜色匹配”；ComfyUI 还会关闭“范围辅助图”，避免模型把黑白蒙版当成画面内容。只有模型输入垫白，历史中的原始捕获及来源图层不改动；离开背景模式后恢复普通编辑偏好。平台适配保留其范围辅助／原生蒙版路径。

主体选择和 RGBA 回填是后续新增的开发改动，目前只做离线回归；下面的实机记录使用此前的背景选区流程，不能证明新流程已经通过宿主或推理验收。读取旧候选继续使用其保存的范围与颜色匹配设置，不会自动反转旧蒙版；复用参数生成新任务时请重新选择主体，新背景任务的颜色匹配会自动关闭。

如果候选的背景仍有明显透明部分，会显示提示并禁用回填；可以另存检查，再手动生成新候选，不会自动重试。2026-10-18 使用“少女站在舞台上”在同一张样图上生成了可见灯光、布景和地面，并在 Photoshop 27 的 RGB8 / Adobe RGB 副本验证回填：人物等选区外区域、额外保护区、来源图层和一次撤销均无像素差异。这不保证每条提示词都得到理想场景；可以进一步描述灯光、布景和地面。以下截图仍记录 v0.4.0；新开关的宿主交互和 16 位背景生成未在本轮验收，旧发行包不含此修正。

## 01 · 局部物体／材质

<p align="center">
  <a href="../../assets/guide/01-edit-compare.png"><img src="../../assets/guide/01-edit-compare.png" width="760" alt="左侧原图，右侧白色过膝袜"></a>
  <br><sub>左：原图 · 右：白色过膝袜</sub>
</p>

1. 复制原样图，选中双腿，从膝盖上方到鞋口，给袜口留一点余量。
2. 选择“局部修图 → 局部物体 / 材质修改”，应用位置选“原选区新图层”，输入下面的提示词。
3. 开启“范围辅助图”“编辑保留原透明轮廓”和“对齐透明主体大小与位置”，关闭颜色匹配。预览选区后生成。
4. 检查双腿都有白袜、袜口高于膝盖、鞋子和腿部姿势没有变，再应用。若对齐导致比例变化，关闭对齐后重新生成。

本次实测提示词：

> 给双腿穿上白色过膝袜，袜口位于膝盖上方；保留腿部姿势、鞋子、原有衣服和透明背景。

实测得到白色过膝袜，原透明轮廓和选区外可见像素保持不变。候选为 800×1216，回填时恢复来源坐标，不需要手工放大来填满画布。

## 02 · 移除

<p align="center">
  <a href="../../assets/guide/02-remove-compare.png"><img src="../../assets/guide/02-remove-compare.png" width="560" alt="左侧原图，右侧移除胸前玩偶"></a>
  <br><sub>左：原图 · 右：移除胸前玩偶</sub>
</p>

1. 复制原样图，套索选中胸前黑色玩偶的头、身体和四肢，稍带周围白色衣料。不要只圈住玩偶中间。
2. 选择“局部修图 → 移除杂物”，应用到原选区。开发版不显示提示词输入，直接按选区移除并补齐周边材质与结构。
3. 开启范围辅助，关闭透明轮廓保留、主体对齐和颜色匹配，预览后生成。
4. 放大检查黑色残片、白色衣褶是否连续、金属链条是否保留，满意后应用。

本次实测提示词：

> 移除胸前的黑色毛绒玩偶挂件，包括头和四肢，在原位置补齐连续的白色褶皱衣料；保留金属链条、人物姿势和其他衣物。

上面的提示词与截图记录旧版测试；开发版使用内置移除指令，不读取其他模式留下的提示词草稿。旧版实测中玩偶移除，白色衣褶接续，金属链条仍在。复杂遮挡未必一次补全；残片处可缩小选区再修一次。

## 03 · 背景

<p align="center">
  <a href="../../assets/guide/03-background-compare.png"><img src="../../assets/guide/03-background-compare.png" width="760" alt="左侧原图，右侧浅紫摄影棚背景"></a>
  <br><sub>左：原图 · 右：浅紫摄影棚背景</sub>
</p>

1. 复制透明样图，使用 Photoshop“选择主体”或手工选中要保留的人物。开发版不需要反选；旧 v0.4.0 的图例使用了反选背景。
2. 选择“局部修图 → 换背景”，应用到原选区，输入下面的提示词。
3. 开发版会自动关闭范围辅助、透明轮廓保留、主体对齐和颜色匹配。预览应显示背景可编辑，人物实心部分被排除。旧 v0.4.0 截图开启了范围辅助，新版行为见[背景替换修正](#background-fix)。
4. 生成并应用，检查四周填满、双脚落地、头发边缘和接触阴影。主体保留方向由背景模式决定；切回普通局部编辑后，选区仍表示要修改的范围。

本次实测提示词：

> 只将透明背景替换为浅薰衣草紫色的简洁摄影棚，柔和均匀的墙面与地面，脚下有轻微接触阴影；完整保留原人物、发丝、衣服、姿势和构图。

## 10 · 光影重塑（开发版）

光影重塑使用独立的大尺寸布光工作台。原图、本地布光示意与 AI 结果分别显示；**布光示意仅用于表达光照意图，最终效果以 AI 生成结果为准。** 模型通过文字理解结构化光源，不能保证精确执行多灯布光，也不提供物理投影或材质模拟。

1. 在已保存的副本中工作，先设置需要保留的保护区。选择“人像 → 光影重塑 → 布光范围”：默认“当前选区”需要编辑选区；“整张图像”明确以全画布减去保护区作为编辑范围，不改变 Photoshop 当前选区。需要改变地面投影时，把承影区域包含在所选范围中。捕获的是当前可见合成图，周边上下文本身不会扩大实际编辑蒙版。
2. 打开布光工作台，核对实际来源名称／文档 ID、范围、配置文件和原图。sRGB 工作副本会显示原文档 ID。缺少选区时会先提示，不先要求授权原文件。主面板的生成入口也只打开工作台，编辑光源不会请求 AI。
3. 添加、选择或拖动光源，也可通过列表选中后在侧栏重命名、复制、禁用、删除或锁定位置，使用“找回”定位画外光源。最多八盏灯；隐藏辅助标记不会关闭光源。缩放、平移和适应窗口只影响显示。工作台撤销／重做处理布光编辑，一次拖动算一步；输入框内保留文本编辑快捷键。
4. 选择点光、聚光或平行光，再选择主光、补光、轮廓光或自定义角色。强度和 Z 均是相对意图；色温与自定义颜色二选一。展开“光源进阶参数”可编辑柔和度及适用的深度、聚光目标／锥角或平行光方向。“全局布光”提供环境光、原有光照处理、阴影和内容保持要求。
5. 在“布光示意”查看近似范围和冷暖变化，需要时填写补充描述。明显冲突必须处理或明确确认后再提交。主动点击工作台“生成”，才冻结当前场景并发起现有模型请求；上传的是干净原图，不含标记、手柄或本地光斑。
6. 生成期间可继续编辑；返回结果若对应旧配置会提示已过期。取消遵循当前后端能力，平台已开始的请求可能仍会完成并计费。来源改变时重新读取，不把旧场景悄悄套到另一张图片。
7. 查看真实 AI 结果，比较五官、文字／Logo、衣物纹理、边缘、高光与阴影。默认应用为 NORMAL 完整结果新图层，带可编辑蒙版；原图不覆盖，可调不透明度或一次撤销。同一捕获的候选重复应用会替换插件自己的结果层。

工作台会在重新捕获或回写时短暂关闭，操作后恢复；这是 PS27 弹窗与文档写入的宿主限制。网络等待不占文档修改锁。配置保存在本机，重新打开要检查来源；明确重新读取或复用才会绑定新的快照。失败时保留布光配置，已保存候选仍可导出。

结构化布光自动关闭主体对齐和上下文颜色匹配，避免抵消有意的光色变化，离开后恢复普通偏好。透明度沿用现有安全策略；不安全的多层半透明来源需要合并副本或导出后手工合成。保留原生 16 位源缓存，模型输入仍是 sRGB8；平台输出为 sRGB8，ComfyUI 可选 SDR16 保存，不代表原生 16 位模型或无损往返。

**实验补偿暂不开放应用。** 数学诊断只适用于对齐、全不透明、同位深的编码 sRGB 数据，分别计算暗部 Multiply 和亮部 Screen。它不是独立物理光照通道，可能包含模型对脸、文字或纹理的改写。拆分不可靠时继续使用完整结果；不会创建空的“光照层”。

重新打开会保留已捕获的范围与编辑过的布光。更改范围时，先关闭工作台，在主面板选择新“布光范围”，再打开并明确点击**重新读取原图**；成功前来源标题保留旧范围，禁止生成。重新读取保留布光配置并绑定新快照，失败则保留旧原图和编辑。复用草稿／历史时使用当前明确选择的来源与范围，不会静默切换范围。此次范围与文件授权修复只有自动 mock 覆盖，新构建的原生捕获、回填、撤销及安装面板仍待验收。

现有九种模式截图不是新工作台验收证据。最终源码已在PS27脚本中验证光源交互、窗口调整及4K八灯预览延迟；自动测试、原生探针和真实模型分别记录。安装后的面板，以及实际人像、产品文字和织物质量仍需验收。实现与测量条件见[开发合同](../development/BACKEND.md#relighting-workbench)。

## 11 · 溶图（开发版）

溶图让已经放入画面的主体适应周围环境。它读取整张当前可见合成图，以主体以外的光照、色温、对比度、纹理与景深为依据，调整选中的主体及边缘；背景只提供参考，保护区继续保留。

1. 在已保存的副本中准备好主体与背景，再选择主体。不要全选画布；单独透明抠图没有可供匹配的环境。
2. 选择“人像 → 溶图”，预览范围。主体外应仅作上下文，需保留的主体细节可另设保护区。
3. 可直接生成，也可补充要求，例如“匹配左侧窗户的暖色光，保留面部结构和衣服纹理”。无需再导入第二张背景参考图。
4. 检查人物身份、姿态、发丝边缘、光影、颗粒与空间关系，再应用为带蒙版的新图层；必要时调整不透明度或一次撤销。

使用全画布上下文，边距参数不裁掉环境；模型分辨率仍有限，小主体的细节可能降低。主体对齐和上下文颜色匹配不会用来抵消溶图。效果依赖模型，不保证身份完全一致，也不是磨皮或把多图简单叠加。本模式目前为离线测试覆盖，真实推理和 Photoshop 控件、边缘与颜色验收仍待完成。

## 候选、进度和撤销

- **进度**：模型加载和文本编码显示阶段；采样开始显示真实步数和百分比，完成显示“候选已保存”。编码可能较久，不要反复提交。
- **多候选**：1–4 张依次生成，锁定种子时批次种子依次递增。点击缩略图或下拉框切换。截图的“候选 4”等编号包含面板之前的结果，不代表本次提交四张。
- **回填**：首次新增带蒙版图层，同次捕获切换候选后可“替换本轮候选图层”。来源尺寸、内容或会话变化时拒绝旧快照，防止写错位置。
- **撤销**：一次 Ctrl+Z 撤销一次应用。不透明度修改有自己的记录；PS 撤销后面板滑块不会实时同步。
- **导出**：“另存 PNG”导出处理后候选，尺寸对应捕获上下文；普通局部编辑不一定是整张画布，开发版溶图和背景模式使用全画布上下文。“新文档查看”打开独立 sRGB 文档。预览是 8 位，导出仍按选择的位深。
- **历史**：先选中表格中的记录行，“读取候选”加载该记录的图片，“复用参数”恢复文字和设置；选区、保护区和参考图要重新准备。重启后的旧结果可以导出／新建文档，不能直接回填重开的原稿。
- **取消／断线**：生成或恢复期间，取消绑定正在处理的任务并停止后续候选，保留已完成结果。空闲时，“取消本任务”和“恢复任务”绑定历史中明确选中的记录。恢复只查询原 ID，不重提交；提示后请在设置中切回保存的后端类型和地址。

开发版持续显示未确认任务数量和**处理未确认任务**入口，切换页面或连接消息不会盖掉它。启动或生成被阻止时，会选中实际阻塞的记录，即使更新的候选已经就绪。历史详情包含完整可复制 UUID、状态、保存的后端、日期、来源文档 ID，以及已保存的来源名称；多个任务可用**下一个未确认任务**逐个查看。处理任务期间锁定历史选择。连续 15 次返回未知或查询连接失败后，结束本地等待并保存 `unknown` 和原 ID；有效的排队／运行回复会重置计数。这不证明远端失败或已取消，请用原 ID 再次**恢复任务**。

历史表格分为**状态、来源、创建时间、任务 ID**四列。点击任一行单元格或纯文字任务 ID 按钮即可选择，边框／底色及**已选中**文字共同标识当前记录；未确认任务也有文字标记。来源名称原样显示，旧记录可退回文档 ID，文字生图或未保存来源会明确说明，不推测缩略图或展示提示词。日期和时间分两行，完整 UUID 与后端详情保留在表格下方。**全部／未确认**显示数量，**上一页／下一页**按保存顺序每页最多显示 20 条。切换筛选或页码后只会选中可见记录，并清除停止跟踪确认；**刷新记录**只重新读取本地历史，不查询或提交后端任务。启动、生成阻塞和未确认任务入口会定位准确 UUID 及所在页；恢复完成后仍选中该行，如终态离开“未确认”筛选则切回“全部”。任务动作等待期间锁定行、筛选、分页和刷新控件。布局面向窄面板，表格显示、键盘及 Photoshop 原生交互仍待宿主验收。

仅 `unknown` 记录提供**停止本地跟踪**：先阅读绑定该 UUID 的警告，再单独点击**我已了解，停止跟踪此 ID**。它只移除此记录的本地生成阻塞，**不会取消远端请求、停止计费、证明失败或删除历史、来源和结果**。新生成仍需主动点击，可能重复执行并计费。记录仍为 `unknown`，标记本地已停止跟踪；选中后点击**恢复任务**会重新跟踪，并在保存的后端查询原 ID。更改选择、刷新历史或重试会清除确认；排队／运行任务不能停止跟踪，其他未确认记录仍会阻止生成。

布光工作台的**处理未确认任务**会关闭弹窗并打开历史中的未确认记录。重新打开时，编辑过的布光和冻结来源仍保留。此次恢复控件有离线 mock 覆盖，Photoshop 原生交互仍待验收。

## 参数与颜色

| 参数 | 怎么用 |
| --- | --- |
| 分辨率 | 768、992、1024；编辑保留长宽比并对齐工作流尺寸。 |
| 步数 | 默认 25，可设 1–100；更高不保证更好。 |
| 上下文边距 | 默认 15%；周边内容供模型参考，不会变成可编辑范围。开发版溶图、换背景与场景替换固定读取整张画布。 |
| 范围辅助图 | 视觉参考；严格保护由最终 PS 灰度蒙版完成。参考图模式默认关闭；开发版 ComfyUI 换背景／场景替换禁用。 |
| 保留原透明轮廓 | 适合衣服、材质编辑；开发版换背景／场景替换禁用。移除或扩大轮廓时也需关闭。 |
| 对齐透明主体 | 按透明边界调整大小位置，可能改变局部比例；开发版换背景／场景替换／溶图自动关闭。 |
| 颜色匹配 | 只校正小幅整体偏色，本轮实测关闭。开发版换背景／场景替换／溶图自动关闭，离开后恢复普通偏好；旧背景候选保留已存设置。 |

16 位结果可另存 PNG16、新建 RGB16 文档、写入已有 16 位文档；写入 8 位文档会降为 8 位，不自动转换来源。模型输入、参考图和选区蒙版仍为 8 位；高位深输出减少后续量化损失，不代表模型有完整 16 位有效精度，也不是 HDR 或原生宽色域生成。生成区仍可能需要 PS 调色。

## 排错与使用边界

| 现象 | 处理 |
| --- | --- |
| 没有选区／编辑区全被保护 | 重新圈选、检查预览，清除不需要的保护区。光影重塑也可明确选择“整张图像”；更改范围后重新读取原图。 |
| 参考图颜色检查失败 | 在副本中确认并嵌入正确 ICC，见角色参考一节。 |
| 换背景只得到黑底／透明底 | 使用开发版的两个背景模式并重新生成，见[背景替换修正](#background-fix)。确认选中要保留的主体；可以写明布景、灯光和地面。读取旧候选不会重新生成，黑白蒙版也不应作为场景参考导入。 |
| 透明图有白底 | 衣服材质编辑开启透明轮廓保留；背景模式关闭。检查原白边和候选 alpha，独立素材仍需清理。 |
| 回填缩小或没填满 | 检查选区、上下文、比例，尝试关闭主体对齐；开发版背景模式选主体并预览全画布范围。不要改工作流尺寸绕过检查。 |
| 来源状态变化，拒绝应用 | 重新捕获生成；旧候选另存 PNG 或新建文档后手工合成。 |
| 半透明多图层无法安全回填 | 保存副本并合并可见层后再生成，或导出手工合成。 |
| 连接、模型、位深错误 | 核对服务、映射、可选保存节点，展开“技术详情”，修正后重试。 |
| PS 整体退出 | 保存工作、记录阶段，结合 Photoshop 事件／转储检查宿主、GPU、驱动和插件。一次成功不能证明永久解决。 |

“宿主诊断 → 图像往返验证”在自己的测试文档中检查选区、保护、蒙版、撤销和回滚；“保存报告”导出结果。“导出运行日志”记录插件阶段，不代替 Photoshop 崩溃转储。

2026-10-17 本轮使用 Windows Photoshop 27.0、GPU 开启及同一张样图：九种模式完成实际生成，六种编辑应用到副本；特效、氛围、文字生图打开 16 位新文档，前两种再与样图实际合成。八份编辑／合成副本的来源图层逐通道一致。六种编辑在有效蒙版外的可见像素及 alpha 无差异，透明保留三例的全画布 alpha 无差异。完全透明像素下不可见的 RGB 不用于合成外观比较，来源图层本身仍逐通道核对。
