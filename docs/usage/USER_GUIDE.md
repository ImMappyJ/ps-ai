## 0.5.0 界面导航

当前面板分为以下区域。导航只切换显示，保留当前模式、提示词、参考图、参数、任务和候选；生成、应用、恢复仍需明确点击。

| 位置 | 内容 |
| --- | --- |
| 创作 | 局部修图／人像／生图、任务模式、输入描述、选区与保护区、参考图、应用位置、生成参数与输出位深。专业参数保留在“进阶参数”中。 |
| 结果 | 当前候选及编号、放大的显示预览、来源与可应用状态、100% 查看、另存 PNG、新文档查看和已应用图层不透明度。 |
| 历史 | 可选中行的记录表格，包含全部／未确认筛选、分页、读取候选、复用参数和恢复入口。明确复用布光时读取当前活动文档。 |
| 设置 | 模型与连接、语言、API Key、配置导入／导出、配置向导和宿主诊断。 |

底部显示当前活动任务状态；切换页面不会停止任务。应用按钮仍区分“应用为新图层”和“替换本轮候选图层”，失效来源或不安全候选保留导出路径。错误摘要显示在对应功能附近；实际成功的重试或重新读取会清除对应的旧错误，开始操作、点击禁用按钮或其他来源的成功不会清除它。历史中的失败任务记录仍保留。“技术详情”直接复制脱敏报告，只有剪贴板写入成功后才显示“已复制”。

光影重塑从“创作 → 人像 → 光影重塑”进入独立布光工作台。其工具栏、光源列表与参数区使用同一视觉样式；原图、布光示意和 AI 结果仍有独立入口。“隐藏标记”只影响显示，“启用此光源”仍决定该光源是否参与布光。

显示预览独立于候选与导出像素，预览清晰度和布局调整不会改写结果。既有任务参数、场景格式和历史保持可读；本轮布光输出默认值的变化见下文。下方截图展示当前布局；安装面板的其他停靠方式、系统缩放及完整宿主流程仍需单独验收。

## 当前行为与验收边界

产品版本为 **0.5.0**，设置中的独立 Git 构建标识区分修订。下文按日期区分原生检查与当前配置截图，不把它们作为当前全功能验收。

打开面板只恢复本地设置和历史元数据，不自动连接后端、扫描模型或启动平台中转。需要时明确点击连接或生成。后台离线不会阻塞面板的本地导航；历史候选在查看时才解码。安装后的 Photoshop 冷启动耗时仍须单独测量。

“完成后自动查看结果”默认开启，可在设置中关闭。主动提交的一批候选全部下载、验证、保存并准备完成后，按任务 ID 定位该批结果一次。正在输入、拖动、打开布光窗口或隐藏面板时延后；不会自动应用到文档。失败、取消或部分成功保留实际已有候选，不当作整批成功。

窄面板的历史默认显示列表，点击记录进入详情，使用“返回历史”回到原筛选、页码、勾选和浏览位置。“全选”仍包含当前筛选的所有页。创作错误不会占据历史页面；空历史不显示空任务表单。

历史浏览与当前结果分开。读取某条候选后，应用动作按该候选保存的任务 UUID 和来源快照判断；切换另一条失效记录不会取消有效候选的权限。来源已修改、关闭或来自旧会话时，可点击“检查来源”查看原因与可用恢复操作；该动作不写入文档。提取失败的光影只保留参考检查／导出，不能通过切换模式应用。

布光的新会话默认选择“光影层”，也可明确选择“整图重绘”。旧任务始终按旧输出类型恢复。光影层使用一次模型目标图作为低分辨率光照参考，在从原文档复制的原生底图上叠加本地影响场；这些场仍可能改变五官、文字和材质的观感。结构不一致或颜色、透明度条件不支持时会拒绝应用，保留参考输出，不自动改用重绘。初始光影层支持 sRGB RGB 8/16 位且实际作用像素不透明；宽色域、灰度和半透明作用区需明确选择原有整图重绘路径。新光影层的真实照片效果需人工验收。

空闲时打开工作台，会读取当前活动 Photoshop 文档的可见合成图，保留编辑过的灯光。新生成的背景、合并图层和手工编辑都按画布当前所见进入来源；“重新读取当前文档”也读取当前活动文档，无需排除结果或另行绑定文档。读取不会改变图层不透明度、可见性或内容。已有候选仍绑定各自提交时的快照，可查看或导出，不能因重读而获得新的应用权限。主面板明确打开时若新读取失败，工作台保持关闭，保留灯光和旧候选并显示来源未更新；已打开的工作台内重读失败才可显示失效旧内容。任务运行期间重开只恢复其冻结上下文，不改动该任务。

原文档上限为 45,000,000 像素，单边不超过 30,000。普通编辑、背景／场景、溶图和整图重绘的大选区在原尺寸读取预算不足时，自动改用有预算的工作图；原生选区、羽化、保护区和回填坐标仍保持原尺寸。面板显示原图、工作图、送模和应用范围。分析分辨率、已有候选及其他会话缓存会影响可用预算；上采样不代表模型生成了原生 4500 万像素细节。

2026-10-19 的 Photoshop 27 原生 API 检查已通过 2400 万像素 RGB8、4500 万像素 RGB16 普通编辑，以及 4500 万像素 RGB8 背景用例的读取、条带回填、写入前取消、选区恢复和单步撤销。采样处来源与保护区保持不变。另用 2315 万像素真实照片副本验证了普通读取、原尺寸回填、全图来源像素保留、单步撤销及写入中途取消回滚。这些 API 检查不代表安装面板、实际 AI 输出或光影质量验收；详见[开发合同](../development/BACKEND.md#relighting-workbench)。

2026-10-19 的条带读取修复解决了局部选区在条带读取中触发的 `Invalid Source Bounds`：只向 Photoshop 请求与选区边界相交的蒙版区域，选区外上下文的蒙版保持零。该问题与 JPG 格式无关。同日使用一张 2002 万像素 sRGB8 JPG 的不规则人物选区，通过了普通全画布上下文、背景和光影的原生读取；逐像素蒙版差异均为零，来源状态未改变。独立羽化样本中的灰度 1、64、128、255 也完整保留。安装后的面板交互仍需单独验收。

光影层采用最多 1,048,576 像素、最长边 1536 的分析副本；原生底图保留文档位深，模型输入仍为 sRGB8。大选区和光影层最终按条带回填到原范围，并受 512,000,000 字节的图像工作集估算门槛约束；这不是 Photoshop 总内存实测，也不保证像素上限内的每个文档都能处理。普通大选区候选的 PNG／新文档使用显示的模型或工作图尺寸，背景候选使用保存的工作图尺寸。成功提取的光影预览、PNG 和新文档使用分析尺寸；提取失败保留实际模型输出尺寸的参考图。完整分辨率结果应先回填，再在 Photoshop 中保存 PSD 或导出。

光影候选的“另存 AI 参考图”导出原样保存的模型输出，与导出本地重组结果的“另存 PNG”分开。该操作不会重新生成，提取失败后仍可另存参考检查。

剪贴板写入使用 UXP 的 `clipboard: readAndWrite` 最小可写权限声明；业务代码只写脱敏报告，不读取剪贴板。复制失败时显示失败并提供诊断导出。新交互、实际拖动手感、大图回填和光影质量不能由旧截图或离线测试替代验收。

## 先连接，再准备副本

1. 安装／加载匹配插件，从 Photoshop“增效工具”打开 PS-AI；Portable 入口为 **PS-AI (Portable)**。
2. 打开“设置 → 模型与连接”，选择 ComfyUI、Nano Banana、GPT Image、BaiLian 或手动服务。云端适配需要对应 API Key，本机中转需要 Node.js 24+；步骤见[平台配置](../setup/PLATFORMS.md)，真实云端输出仍待验收。
3. ComfyUI 路径先启动后端并确认浏览器页面，填写 `http://localhost:8188` 等服务根地址，扫描并选择兼容的 Qwen 2.1 模型、编码器和 VAE，保存配置后连接。地址不含账号、路径或查询；其他架构不能仅靠改名接入。
4. 配置向导可测试地址与环境；最后“生成示例”会明确调用推理后端，并在独立测试文档中应用结果。
5. 回到“创作”，先选模式，再准备已保存来源副本。普通编辑／移除／服装选择要修改的区域；角色参考另需导入图片。背景／场景选择要保留的主体；溶图选择前景主体。移除没有提示词，溶图补充描述可留空。
6. 光影重塑选择当前选区或整张图像进入工作台。图片素材需要放置选区；明确的纯文字素材和文字生图不需要来源选区。预览范围后主动生成，在结果检查并应用或导出；断线时去历史按原 ID 恢复。

开始新的编辑任务时，可从原图建立独立副本，避免前一轮修改影响后续操作。

语言和输出位深切换后保存；地址和模型需点“保存配置”。导出／导入 JSON 可以迁移设置，不包含模型权重和图片历史。CCX 与 Portable 的数据各自独立。

来源需有明确色彩解释，支持 RGB／灰度 8/16 位。无法确认颜色的无 ICC 图片会被拦截；原文件核对与工作副本例外见下文。CMYK、Lab、索引色、位图、多通道、32 位 HDR 请先准备 RGB 副本。历史测试中的原 WebP 是 8 位，副本转为 **RGB / 16 位、sRGB IEC61966-2.1** 验证回填；转换不会补回原图没有的细节。

<a id="source-color"></a>

**读取原图色彩：** 当前文档已有 ICC（包括 Adobe RGB）时，保留当前颜色解释，不需要选择原文件。没有 ICC 且有原文件的 RGB 图片，需要授权读取该原文件；出现选择框时，选择正在编辑的原文件，例如 `3F3F3F.webp`。插件核对路径、尺寸、位深，再读取颜色声明：无 ICC 的静态 WebP 按规范使用 sRGB，PNG 则需要明确的 sRGB 标记。识别成功后会打开一个保留图层的 sRGB 工作副本，预览信息显示采用的规则，生成和“应用为新图层”都面向该副本。原文档不修改，当前未保存的图层也会保留。新增的未标记内容同样按原文件的色彩空间解释；如果之前按其他工作空间调过颜色，请检查副本外观。先前设置的保护区会随坐标一起带到副本；之后继续在这个副本上圈选和生成。

已授权的文件在本次插件会话中复用。**进阶参数 → 记住原图文件授权**默认关闭；开启后在插件私有存储中保存最多 32 个精确文件授权令牌，宿主支持时也会保存本次会话中已经授权的文件。授权和此偏好不随配置、任务历史或诊断日志导出，不保存像素或颜色结论；每次仍读取有大小限制的实际字节并检查颜色声明，同路径文件被替换也不能复用旧的 sRGB 结论。授权失效、文件移动或无法读取时，单次操作最多再打开一次选择框，请重新选择原图。宿主不支持持久令牌或私有存储不可用时，当前已授权读取仍可继续；请查看授权状态中的恢复指引。

取消勾选会移除保存的授权，本次会话访问仍可使用；**清除原图文件授权**还会移除会话授权，以后需要时重新选择原图。私有存储更新失败时，面板会明确报告清除失败并保留可用的会话访问；检查存储并重试清除，不要把失败提示当作已删除。已有有效 ICC 的工作副本不需要重新选择原图。会话内精确文件复用已在本轮有限安装流程观察；记住、清除及失效授权的完整宿主流程仍待验收。

如果取消选择、选错文件、原图超过 64 MB、没有可核对的原文件，或色彩信息无法确认，会停止捕获，不会上传此范围。此时请确认真实色彩空间，在副本中使用“编辑 → 指定配置文件”，再重新捕获。当前版本已在 Photoshop 27 读取本例 WebP，并在独立无 ICC 副本上验证工作副本捕获、等值回填（像素差为 0）、一次撤销和清理，原文档保持不变。本轮另在已安装 0.5.0 b3548bd4 上通过公开 PNG8 的真实原文件选择与整图捕获。修订 4f18ca2 的原生 API 复核分别检查原文档和颜色副本的选区状态；即使副本没有选区，“当前选区”和“整张图像”的完整蒙版 SHA256 都与原始原生蒙版一致。后续安装 291c1d40 已通过缺选区拒绝、真实原文件选择及当前选区捕获复测，工作台正确显示原图和主光；参考导入及更广泛交互仍另行验收。已发布 v0.4.0 仍按上段要求准备带 ICC 的副本。

工作副本的 sRGB 指定保存为独立历史基线。多次撤销到赋色之前时，仅对本次插件会话能核对来源及该历史状态的副本提供“创建已恢复色彩副本并重新读取”。它创建新的已标记副本，保留旧文档及其重做历史；重新读取当前像素、选区和保护区，旧候选仍绑定旧快照。读取失败可在同一个新副本上重试，不重复创建；清除或更新保护区会在重试时生效。已有有效 ICC 优先使用，不选择原文件；未知、旧会话或任意无路径无 ICC 文档仍需确认并手动指定正确配置。PS27 RGB8/16 合成 API 检查通过连续撤销、恢复副本、旧文档保留及一次应用撤销。已安装 b3548bd4 的公开 PNG8 整图用例中，三次 Photoshop 撤销到 NONE 后实际出现恢复入口；明确操作创建并读取新 sRGB 副本，旧文档、已编辑主光和两个旧候选保留，新来源没有自动选中或启用旧候选应用。这是有限安装流程实测，其他来源／范围及后续构建的色彩恢复仍需复测。

如果撤销后的配置文件类型明确为 NONE，即使名称仍残留 sRGB，也不能直接按有效 ICC 读取；这个名称不会单独成为恢复依据。但对本会话已验证且历史、图层和文档状态一致的工作副本，残留名称也不会阻止明确创建恢复副本。插件重启后没有该会话证据的文档仍需手动核对并指定正确配置。

## 参考图片与选区生成素材（0.5.0）

“人像 → 特效素材／氛围素材”的新任务默认“参考当前图片与选区”。先圈出素材位置，必要时另设保护区，再预览：左图是实际送模的 sRGB8 来源，右图是扣除保护区的灰度范围，白色可放置、黑色不放置、灰色保留羽化。当前可见合成和范围图按同一裁切与缩放进入模型；原生来源、选区和保护区另行保存。范围图始终发送，普通编辑的辅助图开关不会将它关闭。

输入方式与应用位置独立。选择“新文档”仍会参考当前图片与选区；只有明确选择“仅文字生成独立素材”才不读取当前图片，此时可另存 PNG 或新建文档。旧无标记任务保留原有含义，复用旧参数会明确选择纯文字；不会为旧任务补传图片或重新提交。额外导入的角色／风格参考图不用于素材。平台不支持图片素材组合时在上传前拒绝，请明确改选纯文字或支持的模型。

选区回填使用保存的原生坐标和有效灰度蒙版一次，素材保留自身透明度，不叠乘来源透明度、不做主体对齐或普通编辑颜色匹配。大区域使用有预算的工作图和原尺寸条带回填。应用前重新核对该 UUID 的来源、范围、位深和历史；来源已修改或关闭时保留导出，不能通过切换历史绕过检查。完全不透明的输出只供另存检查，不能回填。

六个 PS27 合成 API 用例已通过 RGB8/16 的原生素材捕获、灰度选区与保护、透明度和单次羽化、回填及撤销／回滚；小图为 64×48，大图为 4096×4097 RGB8 和 4096×3072 RGB16，并实际使用有界工作图和原尺寸条带。外侧及保护区的可见颜色与 alpha 不变，部分写入后取消也能恢复；透明像素下隐藏 RGB 不在此证明范围。这里使用合成素材与内存任务记录，不是已安装素材控件、磁盘持久化或真实模型效果验收。

另在已安装 0.5.0 291c1d40 上通过小 RGB8 素材流程：矩形选区默认参考当前图片与选区，实际预览为 353×273 来源裁切和有效灰度图，送模尺寸 1120×864。一次明确生成向受控后端发送两次上传、一次 POST，透明蓝色波纹夹具可应用为带可编辑蒙版的独立图层；一次 Photoshop 撤销移除图层，随后从磁盘历史读取同一 UUID 再应用成功，没有新增上传或 POST。原始文档保留，未重复提交。这是实际安装、小 RGB8 与磁盘历史路径证据，不覆盖安装大图／RGB16、重启持久性或真实上游效果。

**本轮五个真实 ComfyUI 样本的视觉检查未通过。** 已实际发送来源与范围，分别测试手部电弧、人物烟雾、透视光束和羽化／面部保护；结果出现来源人物／环境残留或把范围边界画入素材。一次独立的提示词对照仍有残留。透明像素存在不能证明素材合格，请检查深浅背景上的原图残留和范围图痕迹，不能将这些样本当作已验收效果。平台请求有离线验证，但没有 API Key，真实平台输出尚未验收。失败保留原任务和原始输出，恢复只查询原 UUID，不自动重新生成。

## 选区编辑的共同步骤

当前版本在 Photoshop 撤销到较早状态后，选区也可能消失。可以重新圈选后点“预览选区”，或在原模式明确点击“恢复上次选区并重新读取”。后者用本次插件会话最近一次成功捕获的范围替换 Photoshop 选区，保留规范化后的 8 位灰度羽化和原坐标；背景／场景模式恢复要保留的主体。它只用于同一来源文档、尺寸、原生模式／位深和面板模式；重载插件或跨会话需重新圈选。此操作只恢复范围，随后读取当前像素和颜色信息，扣除当前保护区一次并显示新预览。检查后再点“生成候选”；恢复不会提交任务，也不会让旧候选越过文档历史检查。重新读取失败时，已恢复的选区保留，旧来源像素不再用于提交。

“设置 → 构建”显示版本和源码短修订号；`-dirty` 表示包含未提交修改的构建，未打包的源码运行显示 `dev (unbuilt)`。可复制的报错技术详情也包含该标识，用于区分版本号相同的构建。选区恢复与这些控件有离线回归覆盖，安装后 Photoshop 行为和撤销仍需原生验收。

选中范围后点“预览选区”：**橙色可编辑，蓝色为手动保护，灰色只提供上下文**。生成时重新捕获。要保护脸或手，先选中它们“设为保护区”，再重新圈选编辑区。换文档或恢复旧参数后要重新设保护区。

点“生成候选”，等进度结束，检查缩略图和“100% 查看”，再“应用为新图层”。结果带可编辑蒙版，来源图层保留。新模式截图展示配置入口；实际范围请在自己的文档中点击预览确认。

<a id="background-fix"></a>

**0.5.0 的背景替换：** “局部修图 → 换背景”和“人像 → 场景替换”都先选择要保留的主体，无需反选。插件读取整张画布，结合主体选区和原始透明度计算背景回填范围，覆盖主体选区外的透明画布，并处理半透明边缘与新背景的融合。先预览范围，检查不透明主体核心和手工保护区是否排除。两种模式自动关闭“保留原透明轮廓”“对齐透明主体”和“颜色匹配”；ComfyUI 还会关闭“范围辅助图”，避免模型把黑白蒙版当成画面内容。只有模型输入垫白，历史中的原始捕获及来源图层不改动；离开背景模式后恢复普通编辑偏好。平台适配保留其范围辅助／原生蒙版路径。

主体选择和 RGBA 回填是0.5.0 中的后续改动，目前只做离线回归；下面的实机记录使用此前的背景选区流程，不能证明新流程已经通过宿主或推理验收。读取旧候选继续使用其保存的范围与颜色匹配设置，不会自动反转旧蒙版；复用参数生成新任务时请重新选择主体，新背景任务的颜色匹配会自动关闭。

如果候选的背景仍有明显透明部分，会显示提示并禁用回填；可以另存检查，再手动生成新候选，不会自动重试。2026-10-18 使用“少女站在舞台上”在同一张样图上生成了可见灯光、布景和地面，并在 Photoshop 27 的 RGB8 / Adobe RGB 副本验证回填：人物等选区外区域、额外保护区、来源图层和一次撤销均无像素差异。这不保证每条提示词都得到理想场景；可以进一步描述灯光、布景和地面。下方截图展示当前配置入口；新开关的宿主交互和 16 位背景生成仍需分别验收，旧发行包不含此修正。

## 10 · 光影重塑（0.5.0）

强度、色温、范围、深度、柔和度、聚光锥角、方向、仰角及环境／阴影参数采用水平滑块，旁边可精确输入数值。一次连续拖动对应工作台一次撤销；Esc 取消当前手势。键盘与输入同步，灯光类型和颜色模式决定显示哪些参数。拖动只更新本地示意，不捕获图片、不提交任务，也不逐事件保存草稿。

既有 PS27 RGB8/16 合成 API 检查通过实际光影提取、Shadow／Light 原生组、灰度蒙版与保护区、来源保留、一次撤销和失败回滚；原生合成与预览最大差为 1／255、3／65535。真实失败任务按原 UUID 离线读取，拒绝原因现在可区分结构不一致与不支持的边界，原始参考仍可导出。该证据不包括真实照片的保细节质量、全部光影通道或安装面板完整流程；光影视觉效果由用户最终验收。

已安装 0.5.0 b3548bd4 在 PS27 公开 PNG8 与受控本地响应后端上通过有限流程：一次生成对应一次 POST、两次上传；光影组应用及一次 Photoshop 撤销成功；从历史读取同一 UUID 后再应用没有新增 POST。当时的“排除已应用结果并重新读取”保留灯光和旧候选；该控件现已退役，当前重读包含可见结果，无需另行绑定。该历史检查中，失败参考显示“仅供检查”且不能应用。强度滑块 1→3.2 可用一次工作台撤销回到 1，编辑期间没有 POST；输出只有“光影层”和“整图重绘”。此后端没有上游推理，这些记录验证实际安装交互，不证明模型质量、全部控件或最终修订安装已通过。

光影重塑使用独立的大尺寸布光工作台。原图、本地布光示意与 AI 结果分别显示；**布光示意仅用于表达光照意图，应用前需检查准备后的结果。** 光影层由模型参考图提取影响场，整图重绘则使用模型图像本身。模型通过文字理解结构化光源，不能保证精确执行多灯布光，也不提供物理投影或材质模拟。

1. 在已保存的副本中工作，先设置需要保留的保护区。选择“人像 → 光影重塑 → 布光范围”：默认“当前选区”需要编辑选区；“整张图像”明确以全画布减去保护区作为编辑范围，不改变 Photoshop 当前选区。需要改变地面投影时，把承影区域包含在所选范围中。捕获的是当前可见合成图，周边上下文本身不会扩大实际编辑蒙版。
2. 打开布光工作台，核对实际来源名称／文档 ID、范围、配置文件和原图。sRGB 工作副本会显示原文档 ID。缺少选区时会先提示，不先要求授权原文件。主面板的生成入口也只打开工作台，编辑光源不会请求 AI。
3. 添加、选择或拖动光源，也可通过列表选中后在侧栏重命名、复制、禁用、删除或锁定位置，使用“找回”定位画外光源。最多八盏灯；隐藏辅助标记不会关闭光源。缩放、平移和适应窗口只影响显示。工作台撤销／重做处理布光编辑，一次拖动算一步；输入框内保留文本编辑快捷键。
4. 选择点光、聚光或平行光，再选择主光、补光、轮廓光或自定义角色。强度和 Z 均是相对意图；色温与自定义颜色二选一。展开“光源进阶参数”可编辑柔和度及适用的深度、聚光目标／锥角或平行光方向。“全局布光”提供环境光、原有光照处理、阴影和内容保持要求。
5. 在“布光示意”查看近似范围和冷暖变化，需要时填写补充描述。新会话默认“光影层”；需要时明确选择“整图重绘”，并按提示重新读取当前文档。明显冲突必须处理或明确确认后再提交。主动点击工作台“生成 AI 结果”，才冻结当前场景并发起一次模型请求；上传的是受尺寸预算约束的干净来源，不含标记、手柄或本地光斑。
6. 生成期间可继续编辑；返回结果若对应旧配置会提示已过期。取消遵循当前后端能力，平台已开始的请求可能仍会完成并计费。来源改变时重新读取，不把旧场景悄悄套到另一张图片。
7. 查看准备后的结果，比较五官、文字／Logo、衣物纹理、边缘、高光与阴影。光影层应用为一个组，包含原生来源底图及支持的 Shadow、Cast Shadow、Color Atmosphere、Light 和 Rim Light 通道；未观察到的通道会省略。各通道带可编辑蒙版，组蒙版承载实际选区减保护区。整图重绘及旧完整结果任务仍使用带可编辑蒙版的 NORMAL 图像层。原图层不覆盖，可调组／图层不透明度或一次撤销；同一捕获的候选重复应用只替换插件自己的输出。

工作台会在重新捕获或回写时短暂关闭，操作后恢复；这是 PS27 弹窗与文档写入的宿主限制。网络等待不占文档修改锁。配置保存在本机；空闲时从主面板重新打开会读取当前画布，点击“重新读取当前文档”可再次更新。从主面板打开时若读取失败，工作台保持关闭，并显示具体错误；缺少选区时请重新圈选，或明确选择“整张图像”后再打开。原布光和候选继续保留。已经打开的工作台中重新读取失败时仍可检查旧内容，但其来源标为失效，不能提交为当前来源。生成或应用后的内部恢复弹窗仍显示对应任务的冻结上下文，不会顺带重新捕获。成功重新读取会清除该来源的旧读取错误。关闭工作台会停止来源监听与预览，不会取消已经提交的任务。

结构化布光自动关闭主体对齐和上下文颜色匹配，避免抵消有意的光色变化，离开后恢复普通偏好。光影层要求作用像素不透明且来源为有标签的 sRGB RGB 8/16 位；原生回填会复查透明度并在不支持时回滚。明确选择的整图重绘沿用既有透明度安全策略，不安全的多层半透明来源需要合并副本或导出后手工合成。保留原生 16 位源数据，模型输入仍是 sRGB8；平台输出为 sRGB8，ComfyUI 可选 SDR16 保存，不代表原生 16 位模型或无损往返。

工作台只提供“整图重绘”和“光影层”两种输出，旧补偿实验及其诊断入口已移除。光影场仍是估计，不是独立物理光照通道。提取失败时保留参考图供检查与导出，不会静默切换为整图重绘，也不会创建空的光影组。

更改范围时，先关闭工作台，在主面板选择新“布光范围”，再打开；工作台读取当前文档和所选范围并保留编辑过的布光，不需要再执行第二次绑定。成功前禁止生成，读取失败则保留旧原图和编辑并显示未更新原因。复用草稿／历史时使用当前明确选择的来源与范围，不会重提历史任务。上方记录的旧版有限安装流程不证明本次当前画布读取已通过；本次回归、原生与安装证据另行记录。

当前配置截图不能代替完整工作台验收。较早源码已在 PS27 脚本中验证光源交互、窗口调整及 4K 八灯预览；其延迟数据属于旧预览实现。2026-10-19 本地时间的独立 PS27 合成 API 检查验证了 1024×300 sRGB 8/16 位来源保留、隐藏组还原和一次撤销，以及 9000×5000 RGB8 的分析捕获、条带写入和一次撤销。羽化蒙版复核中保护区无变化，原生合成与本地预览最大差分别为 2／255、3／65535。这不包括真实照片效果、新推理、4500 万像素 RGB16 或安装面板。实际人像、产品文字、织物、来源同步交互及完整宿主流程仍需验收。实现与测量条件见[开发合同](../development/BACKEND.md#relighting-workbench)。

## 11 · 溶图（0.5.0）

![0.5.0 溶图配置入口，尚未生成](../../assets/guide/050-mode-blend-zh.png)

溶图让已经放入画面的主体适应周围环境。它读取整张当前可见合成图，以主体以外的光照、色温、对比度、纹理与景深为依据，调整选中的主体及边缘；背景只提供参考，保护区继续保留。

1. 在已保存的副本中准备好主体与背景，再选择主体。不要全选画布；单独透明抠图没有可供匹配的环境。
2. 选择“人像 → 溶图”，预览范围。主体外应仅作上下文，需保留的主体细节可另设保护区。
3. 可直接生成，也可补充要求，例如“匹配左侧窗户的暖色光，保留面部结构和衣服纹理”。无需再导入第二张背景参考图。
4. 检查人物身份、姿态、发丝边缘、光影、颗粒与空间关系，再应用为带蒙版的新图层；必要时调整不透明度或一次撤销。

ComfyUI 的新溶图任务只发送当前合成图及可选角色参考，不发送灰度范围辅助图；该图会作为普通参考图进入 Qwen 编码，可能干扰布光。选区、羽化和保护区仍完整保存，由 Photoshop 的原尺寸蒙版精确限制回填。平台后端保留各自的范围图／原生蒙版路径。模式与后端切换后恢复普通辅助图偏好，旧候选沿用保存的任务，不会自动重新生成。

新内置指令用于所有后端，要求根据环境重新匹配曝光、受光方向、阴影和环境反射色，并保留插画或摄影风格；只有省略灰度范围参考这一项限于 ComfyUI。使用全画布上下文，边距参数不裁掉环境；模型分辨率仍有限，小主体的细节可能降低。主体对齐和上下文颜色匹配不会用来抵消溶图。效果依赖模型，不保证身份、线条和纹理完全一致，也不是磨皮或把多图简单叠加。

2026-10-20 使用现有 Qwen 2.1 模型、原输入和固定种子做了两组真实推理对照。插画主体在去掉范围参考后出现明显明暗调整；真人样本仍变化较弱，不能据此认为真人溶图质量已经解决。按保存的主体蒙版合成的本地预览保留了范围外背景，但改动更大不等于效果更好，五官、画风、细节和边缘仍需目视验收。真人预览使用有界分析图；此对照不能替代新版已安装 Photoshop 控件、原尺寸回填和颜色验收。

另在 Photoshop 27 已安装的 0.5.0 d2966347 Portable 上验证小 RGB8 合成文档：溶图自动关闭范围辅助图，退出后恢复普通编辑偏好；整幅来源预览成功，一次生成向独立受控后端发送一次原图上传、一次 POST，没有范围图或重复提交。实际回填创建带蒙版的新图层，原图层、范围外像素及 alpha 不变；一次 Photoshop 撤销精确恢复原合成像素和历史基线。此项仅验证 64×48 来源的安装交互，不是真实推理质量、羽化权重精确值、保护区、大图、16 位或平台验收。

## 候选、进度和撤销

- **进度**：模型加载和文本编码显示阶段；采样开始显示真实步数和百分比，完成显示“候选已保存”。编码可能较久，不要反复提交。
- **多候选**：1–4 张依次生成，锁定种子时批次种子依次递增。点击缩略图或下拉框切换。候选编号只用于在保存的结果之间定位，不是本轮补拍的生成验收。
- **回填**：首次新增带蒙版图层，同次捕获切换候选后可“替换本轮候选图层”。来源尺寸、内容或会话变化时拒绝旧快照，防止写错位置。
- **撤销**：一次 Ctrl+Z 撤销一次应用。不透明度修改有自己的记录；PS 撤销后面板滑块不会实时同步。
- **导出**：“另存 PNG”导出处理后候选，尺寸对应捕获上下文；普通局部编辑不一定是整张画布，当前版本溶图和背景模式使用全画布上下文。“新文档查看”打开独立 sRGB 文档。预览是 8 位，导出仍按选择的位深。
- **历史**：点击左侧记录，在右侧查看详情和本地预览；“读取候选”将该记录加载到结果页，“复用参数”恢复文字和设置。选区、保护区和参考图要重新准备。重启后的旧结果可以导出／新建文档，不能直接回填重开的原稿。
- **取消／断线**：生成或恢复期间，取消绑定正在处理的任务并停止后续候选，保留已完成结果。空闲时，“取消本任务”和“恢复任务”绑定历史中明确选中的记录。恢复只查询原 ID，不重提交；提示后请在设置中切回保存的后端类型和地址。

当前版本持续显示未确认任务数量和**处理未确认任务**入口，切换页面或连接消息不会盖掉它。启动或生成被阻止时，会选中实际阻塞的记录，即使更新的候选已经就绪。历史详情包含完整可复制 UUID、状态、保存的后端、日期、来源文档 ID，以及已保存的来源名称；多个任务可用**下一个未确认任务**逐个查看。处理任务期间锁定历史选择。连续 15 次返回未知或查询连接失败后，结束本地等待并保存 `unknown` 和原 ID；有效的排队／运行回复会重置计数。这不证明远端失败或已取消，请用原 ID 再次**恢复任务**。

历史采用**左侧列表、右侧详情与预览**。列表显示日期、任务类型、原样提示词摘要和状态；右侧显示完整提示词、UUID、来源及保存的后端。移除模式显示内置指令说明，缺少参数或提示词的旧记录显示对应提示。列表与详情分别滚动，窄面板上下排列。预览只读取本地文件并进行现有图片校验，不改变结果页、不查询后端；没有候选或文件损坏时显示说明。

**全部／未确认**显示数量，**上一页／下一页**每页最多显示 20 条。点击记录查看详情；勾选框用于选择一条或多条待清除记录，两种选择分别标识。**全选**覆盖当前筛选的所有页，显示已勾选数量；翻页保留勾选，切换筛选清空勾选。**刷新记录**只重新读取本地历史。未确认任务入口定位准确 UUID 及所在页，同时展示该任务的详情和操作；恢复完成后仍选中该行，如终态离开“未确认”筛选则切回“全部”。任务动作等待期间锁定选择、分页、刷新和清除。新布局、滚动和键盘操作只有离线覆盖，Photoshop 原生交互仍待验收。

**清除勾选历史**会先显示数量和影响说明，再点击**确认清除这些记录**。它删除勾选的本地历史及插件保存的来源、蒙版和候选文件，清除内存中的对应候选；原始 Photoshop 文档、已应用图层、已导出的图片、设置、文件授权和布光草稿保留。空闲时也可清除无法恢复的遗留排队、运行、取消确认中或未知任务，解除这些记录的本地生成阻挡。**这不取消远端任务、不保证停止计费，后端保存的数据也不会删除**；清除后不能再通过该历史记录恢复任务。其他未确认记录仍会阻挡生成，新生成需要另行点击。

清理中断后，已确认清除的记录不会因重启重新出现并阻挡生成；有待清理的文件或历史元数据时，可点击**重试本地清理**。仍被其他记录引用的文件暂时保留，无法确认归属的非标准文件名会跳过并提示，不会删除任意路径或目录。请依据清理状态判断是否全部完成。

仅 `unknown` 记录提供**停止本地跟踪**：先阅读绑定该 UUID 的警告，再单独点击**我已了解，停止跟踪此 ID**。它只移除此记录的本地生成阻塞，**不会取消远端请求、停止计费、证明失败或删除历史、来源和结果**。新生成仍需主动点击，可能重复执行并计费。记录仍为 `unknown`，标记本地已停止跟踪；选中后点击**恢复任务**会重新跟踪，并在保存的后端查询原 ID。更改选择、刷新历史或重试会清除确认；排队／运行任务不能停止跟踪，其他未确认记录仍会阻止生成。

布光工作台的**处理未确认任务**会关闭弹窗并打开历史中的未确认记录。重新打开时，编辑过的布光和冻结来源仍保留。此次恢复控件有离线 mock 覆盖，Photoshop 原生交互仍待验收。

16 位结果可另存 PNG16、新建 RGB16 文档、写入已有 16 位文档；写入 8 位文档会降为 8 位，不自动转换来源。模型输入、参考图和选区蒙版仍为 8 位；高位深输出减少后续量化损失，不代表模型有完整 16 位有效精度，也不是 HDR 或原生宽色域生成。生成区仍可能需要 PS 调色。

## 排错与使用边界

| 现象 | 处理 |
| --- | --- |
| 没有选区／编辑区全被保护 | 重新圈选、检查预览，清除不需要的保护区。光影重塑也可明确选择“整张图像”；更改范围后重新读取当前文档。 |
| 参考图颜色检查失败 | 在副本中确认并嵌入正确 ICC，见角色参考一节。 |
| 换背景只得到黑底／透明底 | 使用当前版本的两个背景模式并重新生成，见[背景替换修正](#background-fix)。确认选中要保留的主体；可以写明布景、灯光和地面。读取旧候选不会重新生成，黑白蒙版也不应作为场景参考导入。 |
| 透明图有白底 | 衣服材质编辑开启透明轮廓保留；背景模式关闭。检查原白边和候选 alpha，独立素材仍需清理。 |
| 回填缩小或没填满 | 检查选区、上下文、比例，尝试关闭主体对齐；当前版本背景模式选主体并预览全画布范围。不要改工作流尺寸绕过检查。 |
| 来源状态变化，拒绝应用 | 重新捕获生成；旧候选另存 PNG 或新建文档后手工合成。 |
| 半透明多图层无法安全回填 | 保存副本并合并可见层后再生成，或导出手工合成。 |
| 连接、模型、位深错误 | 核对服务、映射、可选保存节点，展开“技术详情”，修正后重试。 |
| PS 整体退出 | 保存工作、记录阶段，结合 Photoshop 事件／转储检查宿主、GPU、驱动和插件。一次成功不能证明永久解决。 |

“宿主诊断 → 图像往返验证”在自己的测试文档中检查选区、保护、蒙版、撤销和回滚；“保存报告”导出结果。“导出运行日志”记录插件阶段，不代替 Photoshop 崩溃转储。

2026-10-17 的历史检查使用 Windows Photoshop 27.0、GPU 开启及同一张样图：九种模式完成实际生成，六种编辑应用到副本；特效、氛围、文字生图打开 16 位新文档，前两种再与样图实际合成。八份编辑／合成副本的来源图层逐通道一致。六种编辑在有效蒙版外的可见像素及 alpha 无差异，透明保留三例的全画布 alpha 无差异。完全透明像素下不可见的 RGB 不用于合成外观比较，来源图层本身仍逐通道核对。

上述历史通过范围限于当时的具体操作和效果，不是本轮配置补拍的生成结果。服装验证了衣摆编辑，参考验证了白袜迁移；复杂道具重建、身份一致性、其他模型、校准显示器色准、长时间稳定性尚未覆盖。测试期间未发生 Photoshop 整体退出，不能保证以后不崩溃。角色参考、特效和氛围仍属实验能力；不做常规磨皮和去痘。
